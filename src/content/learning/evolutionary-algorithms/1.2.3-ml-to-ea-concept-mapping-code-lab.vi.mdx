## Mục tiêu Thực hành

Cách tốt nhất để hiểu sâu Thuật toán Tiến hóa là tự tay lập trình một vòng lặp tiến hóa hoàn chỉnh để giải bài toán quen thuộc nhất: **Hồi quy Tuyến tính (Linear Regression)**:

<BlockMath formula="\hat{y} = w \cdot x + b" />

Chúng ta sẽ tìm cặp tham số tối ưu <InlineMath formula="(w, b)" /> mà **hoàn toàn KHÔNG dùng bất kỳ phép tính đạo hàm hay gradient nào**. Chỉ dùng:
1. Đánh giá hàm mất mát MSE làm điểm Fitness.
2. Chọn lọc top các cá thể tốt nhất (Elitism).
3. Đột biến bằng cách cộng nhiễu phân phối chuẩn.

## Tạo Dữ liệu Hồi quy Mẫu

Khởi tạo một tập dữ liệu đồ thị đường thẳng nhân tạo với phương trình thực: <InlineMath formula="y = 3.5x + 1.2 + \text{noise}" />:

```python
import numpy as np

# Cố định seed để tái lập kết quả
np.random.seed(42)

# Sinh 100 điểm dữ liệu mẫu
X = np.random.uniform(-3.0, 3.0, size=(100, 1))
TRUE_W = 3.5
TRUE_B = 1.2
y = TRUE_W * X + TRUE_B + np.random.normal(0, 0.4, size=(100, 1))

print(f"Dataset: 100 mẫu | Ground Truth: w = {TRUE_W}, b = {TRUE_B}")
```

```output
Dataset: 100 mẫu | Ground Truth: w = 3.5, b = 1.2
```

## Khởi tạo Quần thể: 60 Đường thẳng Ngẫu nhiên

Mỗi cá thể trong bài toán này mang cặp gen <InlineMath formula="[w_i, b_i]" />. Vì phương trình là <InlineMath formula="\hat{y} = w_i \cdot x + b_i" />, **mỗi cá thể chính là một đường thẳng cụ thể** trên mặt phẳng tọa độ!

Khởi tạo ngẫu nhiên một quần thể gồm 60 cá thể từ phân phối chuẩn:

```python
# Khởi tạo Quần thể: 60 cá thể ngẫu nhiên mang cặp gen [w, b]
```

## Đánh giá & Chọn lọc: Giữ 10 Đường Tốt Nhất (Elites)

Bây giờ ta tiến hành chấm điểm toàn bộ 60 đường thẳng bằng hàm mất mát MSE, sau đó lọc ra **Top 10 đường tốt nhất (Elites)**:

```python
# 1. Đánh giá (Evaluation): Tính MSE cho toàn bộ 60 cá thể
w = population[:, 0:1, np.newaxis] # shape: (60, 1, 1)
b = population[:, 1:2, np.newaxis] # shape: (60, 1, 1)
y_preds = w * X.T + b              # shape: (60, 1, 100)
mse_losses = np.mean((y_preds - y.T)**2, axis=2).flatten()

best_idx = np.argmin(mse_losses)
print(f"Thế hệ 0 | Cá thể tốt nhất: w = {population[best_idx, 0]:.3f}, b = {population[best_idx, 1]:.3f}")
print(f"MSE ban đầu (còn rất cao): {mse_losses[best_idx]:.4f}")

# 2. Chọn lọc (Selection)
top_k = 10
sorted_indices = np.argsort(mse_losses)
elites = population[sorted_indices[:top_k]]
print(f"MSE trung bình của Top 10 Elite: {np.mean(mse_losses[sorted_indices[:top_k]]):.4f}")
```


## Sinh sản & Đột biến để Tạo Thế hệ Con

Sau khi đã giữ lại 10 cá thể ưu tú (Elites), làm thế nào để khôi phục lại quy mô quần thể về 60 cá thể cho thế hệ tiếp theo?

Ta áp dụng cơ chế **Nhân bản có biến dị (Asexual Reproduction with Gaussian Mutation)**:

```python
# 1. Nhân bản: Chọn ngẫu nhiên có hoàn lại từ Top 10 Elite để tạo 50 bản sao
parent_indices = np.random.choice(top_k, size=pop_size - top_k)
offspring_copies = elites[parent_indices]

# 2. Đột biến: Cộng nhiễu phân phối chuẩn Gaussian N(0, sigma) vào từng trọng số
mutation_sigma = 0.1
mutations = np.random.normal(0, mutation_sigma, size=offspring_copies.shape)
offspring = offspring_copies + mutations

# 3. Tạo Quần thể thế hệ mới: 10 Elite gốc + 50 cá thể con đột biến
new_population = np.vstack([elites, offspring])

print("Kích thước quần thể thế hệ 1:", new_population.shape)
print(f"Số lượng Elite bảo tồn nguyên vẹn: {len(elites)}")
print(f"Số lượng cá thể con đột biến: {len(offspring)}")
print("\nVí dụ: 1 cá thể cha mẹ và cá thể con sau khi đột biến:")
print(f"  Elite cha mẹ : w = {offspring_copies[0, 0]:.3f}, b = {offspring_copies[0, 1]:.3f}")
print(f"  Con đột biến : w = {offspring[0, 0]:.3f}, b = {offspring[0, 1]:.3f}")
```

## Đóng gói Vòng lặp Tiến hóa qua 50 Thế hệ

Bây giờ ta đóng gói toàn bộ quy trình trên vào một hàm hoàn chỉnh và cho tiến hóa tự động qua 50 thế hệ:

```python
def evolve_linear_regression(X, y, pop_size=60, generations=50, top_k=10, mutation_sigma=0.1):
    population = np.random.randn(pop_size, 2)
    history_loss = []
    gen0_best = None

    for gen in range(generations):
        # Đánh giá (Evaluation)
        w = population[:, 0:1, np.newaxis]
        b = population[:, 1:2, np.newaxis]
        y_preds = w * X.T + b
        mse_losses = np.mean((y_preds - y.T)**2, axis=2).flatten()

        sorted_indices = np.argsort(mse_losses)
        elites = population[sorted_indices[:top_k]]

        history_loss.append(mse_losses[sorted_indices[0]])
        if gen == 0:
            gen0_best = elites[0].copy()

        # Sinh sản & Đột biến (Reproduction & Mutation)
        offspring_copies = elites[np.random.choice(top_k, size=pop_size - top_k)]
        mutations = np.random.normal(0, mutation_sigma, size=offspring_copies.shape)
        offspring = offspring_copies + mutations

        population = np.vstack([elites, offspring])

        if (gen + 1) % 10 == 0 or gen == 0:
            best_loss = mse_losses[sorted_indices[0]]
            best_w, best_b = elites[0]
            print(f"Gen {gen+1:02d} | Best MSE: {best_loss:.4f} | w = {best_w:.3f}, b = {best_b:.3f}")

    return elites[0], history_loss, gen0_best

best_params, history_loss, gen0_params = evolve_linear_regression(X, y)
```

## So sánh Nghiệm Tiến hóa với Scikit-Learn Baseline

So sánh kết quả của thuật toán tiến hóa với nghiệm least-squares do Scikit-Learn tính bằng solver số ổn định:

