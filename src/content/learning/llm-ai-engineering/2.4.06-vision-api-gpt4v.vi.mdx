Support app nhận ảnh kiện hàng, kiểm tra MIME, size, tenant ownership rồi gửi part cùng câu hỏi. Output `{damage:true}` vẫn cần human review trước refund.

| Boundary | Rule bắt buộc |
|---|---|
| Upload | Xác thực tenant/ownership; giới hạn byte và pixel trước decode |
| Media | Allowlist MIME theo magic bytes, không chỉ extension hay header |
| Provider | Gửi bytes/file reference đã authorize; không tạo public URL mặc định |
| Output | Validate schema; human review trước refund hoặc side effect |
| Retention | Xóa upload/provider resource theo policy và audit deletion |

<LessonNote>Vision output là evidence không chắc chắn, không phải authorization. EXIF, OCR text và URL do user cung cấp đều là dữ liệu không tin cậy.</LessonNote>

**Pitfalls:**

- Cho model fetch URL tùy ý gây SSRF/data leak.
- Tin OCR/vision output như fact chắc chắn.
- Hard-code model alias hoặc context cost.
