**Mục tiêu:** Viết một classifier toy nhưng chạy độc lập và giữ cùng contract với LLM classifier thực tế.

- `input_ids: (B,T)` integer;
- `attention_mask: (B,T)` với 1 cho nội dung;
- `labels: (B,)`;
- output `logits: (B,K)`.

Ta dùng embedding + MLP nhỏ làm backbone để smoke test không cần checkpoint lớn. Trong dự án thật, thay backbone bằng GPT đã pretrain.

<CodeLessonFrame
  title="Backbone giữ hidden theo token"
  contract="input IDs (B,T) → token hidden (B,T,C)"
  output="TinyBackbone dùng embedding + MLP"
  takeaway="Giữ boundary (B,T,C) để thay backbone mà không đổi classifier."
>

```python
import torch
from torch import nn

class TinyBackbone(nn.Module):
    def __init__(self, vocab_size, d_model):
        super().__init__()
        self.token_emb = nn.Embedding(vocab_size, d_model)
        self.mlp = nn.Sequential(
            nn.Linear(d_model, d_model),
            nn.GELU(),
        )

    def forward(self, input_ids):
        return self.mlp(self.token_emb(input_ids))
```

Contract: `(B,T) → (B,T,C)`.

<LessonNote>**Production:** GPT backbone còn có positional embedding và causal transformer blocks; head code phía sau không cần biết chi tiết đó.</LessonNote>

<CodeLessonFrame
  title="Chọn token cuối và chiếu sang class"
  contract="hidden (B,T,C) + right-padding mask → last hidden (B,C) → logits (B,K)"
  output="Device-safe gather theo valid_count − 1"
  pitfall="CPU smoke test có thể che lỗi last_index khác device với hidden khi chạy GPU."
  takeaway="Mask quyết định vị trí đọc; head quyết định số class."
>

```python
class TextClassifier(nn.Module):
    def __init__(self, backbone, d_model, num_classes):
        super().__init__()
        self.backbone = backbone
        self.head = nn.Linear(d_model, num_classes)

    def forward(self, input_ids, attention_mask):
        if input_ids.ndim != 2 or attention_mask.shape != input_ids.shape:
            raise ValueError("input_ids and attention_mask must both be (B,T)")
        if attention_mask.device != input_ids.device:
            raise ValueError("attention_mask must be on input_ids.device")
        binary_mask = attention_mask.to(dtype=torch.long)
        if not torch.all((binary_mask == 0) | (binary_mask == 1)):
            raise ValueError("attention_mask must contain only 0 or 1")
        if torch.any(binary_mask[:, 1:] > binary_mask[:, :-1]):
            raise ValueError("this classifier requires right padding")

        hidden = self.backbone(input_ids)
        B = input_ids.size(0)
        valid_count = binary_mask.sum(dim=1)
        if torch.any(valid_count == 0):
            raise ValueError("every sample needs at least one content token")
        last_index = (valid_count - 1).to(device=hidden.device)
        batch_index = torch.arange(B, device=hidden.device)
        last_hidden = hidden[batch_index, last_index]
        return self.head(last_hidden)
```

<CodeLessonFrame
  title="Một training step"
  contract="logits (B,K) + labels (B,) → scalar CE → optimizer step"
  output="requires_grad điều khiển head-only policy"
  pitfall="Freeze backbone không có nghĩa bỏ backbone khỏi forward."
  takeaway="Freeze policy được biểu diễn bằng requires_grad."
>

```python
import torch.nn.functional as F

model.train()
optimizer.zero_grad()
logits = model(input_ids, attention_mask)
loss = F.cross_entropy(logits, labels)
loss.backward()
optimizer.step()

assert logits.shape == (input_ids.size(0), num_classes)
assert torch.isfinite(loss)
```

Để train head-only:

```python
for parameter in model.backbone.parameters():
    parameter.requires_grad = False
```

<LessonNote>**Production:** theo dõi validation loss/accuracy, class imbalance, gradient clipping và checkpoint; một batch không đủ đánh giá.</LessonNote>

<CodeLessonFrame
  title="Smoke test độc lập"
  contract="shape + finite loss + empty-mask error path"
  output="torch.Size([2, 2])"
  takeaway="Smoke test khóa contract; benchmark trên split độc lập mới xác nhận chất lượng."
>

```python
import torch
from torch import nn
import torch.nn.functional as F

torch.manual_seed(7)
vocab_size, d_model, num_classes = 20, 8, 2
model = TextClassifier(
    TinyBackbone(vocab_size, d_model),
    d_model,
    num_classes,
)
optimizer = torch.optim.AdamW(model.parameters(), lr=1e-2)

input_ids = torch.tensor([[3, 4, 5, 0], [8, 9, 0, 0]])
attention_mask = torch.tensor([[1, 1, 1, 0], [1, 1, 0, 0]])
labels = torch.tensor([1, 0])

logits = model(input_ids, attention_mask)
loss = F.cross_entropy(logits, labels)
assert logits.shape == (2, 2)
assert loss.ndim == 0 and torch.isfinite(loss)

try:
    model(input_ids[:1], torch.zeros_like(attention_mask[:1]))
except ValueError:
    pass
else:
    raise AssertionError("all-zero attention mask must fail")

print(logits.shape)  # torch.Size([2, 2])
```
