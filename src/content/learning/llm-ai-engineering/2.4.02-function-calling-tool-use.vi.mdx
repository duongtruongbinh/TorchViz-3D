## Capability và common contract

Model chỉ đề xuất tool name/arguments; application mới sở hữu validation, authorization và execution.

**Input:** Tool JSON Schemas, authenticated user intent và model response items.

**Output:** Validated tool result hoặc typed rejection rồi final model response.

**Data/type/shape:** Tool call `{id,name,arguments}` parse thành domain command; result giữ call ID để nối đúng vòng.

## Worked fixture

`lookup_order({orderId:'A17'})` pass schema nhưng chỉ chạy sau ownership check. Unknown tool, extra property hoặc sai enum trả structured error; không dùng `eval`.

~~~ts
import assert from "node:assert/strict";
type Call = { id: string; name: string; arguments: string };
type ToolResult =
  | { type: "tool_result"; callId: string; output: { status: string } }
  | { type: "tool_error"; callId: string; code: string };

function execute(call: Call, ownedOrders: Set<string>): ToolResult {
  if (call.name !== "lookup_order") {
    return { type: "tool_error", callId: call.id, code: "unknown_tool" };
  }
  let raw: unknown;
  try { raw = JSON.parse(call.arguments); }
  catch { return { type: "tool_error", callId: call.id, code: "invalid_json" }; }
  if (
    typeof raw !== "object" || raw === null ||
    Object.keys(raw).length !== 1 ||
    typeof (raw as { orderId?: unknown }).orderId !== "string"
  ) {
    return { type: "tool_error", callId: call.id, code: "invalid_arguments" };
  }
  const orderId = (raw as { orderId: string }).orderId;
  if (!ownedOrders.has(orderId)) {
    return { type: "tool_error", callId: call.id, code: "forbidden" };
  }
  return { type: "tool_result", callId: call.id, output: { status: "in_transit" } };
}

const allowed = execute(
  { id: "call_17", name: "lookup_order", arguments: '{"orderId":"A17"}' },
  new Set(["A17"]),
);
assert.deepEqual(allowed, {
  type: "tool_result", callId: "call_17", output: { status: "in_transit" },
});
assert.equal(
  execute({ id: "call_18", name: "lookup_order", arguments: '{"orderId":"B9"}' },
          new Set(["A17"])).type,
  "tool_error",
);
~~~
<LessonNote>Loop production còn phải cap số bước/call song song, dùng idempotency cho side effect và trả tool result bằng đúng call ID. Arguments luôn là dữ liệu không tin cậy.</LessonNote>

## Production delta và handoff

**Pitfalls:**

- Tin arguments vì schema đã khai báo.
- Cho model tự thực thi privileged action.
- Không cap parallel calls/steps.

<LessonNote>Nguồn official kiểm tra 2026-07-23: [tài liệu hiện hành](https://developers.openai.com/api/docs/guides/function-calling). Model, limit, price và capability phải được kiểm tra lại tại thời điểm triển khai.</LessonNote>

**Kết nối:** Structured Outputs áp schema cho response không phải tool.
