Orchestrator waits readiness 200 before traffic, queries model ID, runs schema/tool conformance test, and scrapes latency/queue metrics. Unsupported Batch/admin path is not assumed.

| Probe | Ý nghĩa | Traffic decision |
|---|---|---|
| Process liveness | Container/process còn chạy | Chưa đủ để nhận request |
| Readiness | Model/runtime sẵn sàng phục vụ | Mới được thêm vào pool |
| `/v1/models` | Exact inference model ID | Reject config không tồn tại |
| Text/tool/schema fixture | Phần compatibility thực sự hỗ trợ | Chỉ advertise capability đã pass |
| Queue/latency/error metrics | Capacity health | Scale, drain hoặc circuit-break |

<LessonNote>Inference endpoints và management/readiness endpoints là hai bề mặt riêng. “OpenAI-compatible” không hứa Batch, admin hoặc mọi field upstream.</LessonNote>
