## Pattern và contract

Provider quota và per-user app limit là hai lớp khác nhau. Router cần RPM/TPM/concurrency headroom theo provider/model.

**Input:** Current reservations/usage, request estimated tokens và provider headers.

**Output:** Admit, delay, queue, reroute hoặc reject.

**Data/type/shape:** Multi-dimensional counters, không một scalar QPS; reservation được release/reconcile khi terminal.

## Worked scenario

Provider còn 10 RPM nhưng chỉ 2.000 TPM; request 3.000 token không được admit dù RPM đủ. Reservation tránh hai workers cùng tiêu headroom.

~~~ts
import assert from "node:assert/strict";
type Headroom = { rpm: number; tpm: number; concurrency: number };
type Reservation = { requests: number; tokens: number; slots: number };
type Decision =
  | { kind: "admit"; remaining: Headroom }
  | { kind: "delay"; constrainedBy: Array<keyof Headroom> };

function reserve(headroom: Headroom, request: Reservation): Decision {
  const constrainedBy: Array<keyof Headroom> = [];
  if (request.requests > headroom.rpm) constrainedBy.push("rpm");
  if (request.tokens > headroom.tpm) constrainedBy.push("tpm");
  if (request.slots > headroom.concurrency) constrainedBy.push("concurrency");
  if (constrainedBy.length) return { kind: "delay", constrainedBy };
  return {
    kind: "admit",
    remaining: {
      rpm: headroom.rpm - request.requests,
      tpm: headroom.tpm - request.tokens,
      concurrency: headroom.concurrency - request.slots,
    },
  };
}

assert.deepEqual(
  reserve(
    { rpm: 10, tpm: 2_000, concurrency: 4 },
    { requests: 1, tokens: 3_000, slots: 1 },
  ),
  { kind: "delay", constrainedBy: ["tpm"] },
);
assert.deepEqual(
  reserve(
    { rpm: 10, tpm: 2_000, concurrency: 4 },
    { requests: 1, tokens: 1_200, slots: 1 },
  ),
  { kind: "admit", remaining: { rpm: 9, tpm: 800, concurrency: 3 } },
);
~~~
<LessonNote>Trong nhiều workers, reserve/release/reconcile phải atomic ở shared store. Provider headers là provider-specific evidence; local reservations vẫn cần khi header thiếu.</LessonNote>

## Failure modes và handoff

**Pitfalls:**

- Chỉ track request count.
- Không reconcile failed calls.
- Dùng local counter sau load balancer.

**Kết nối:** Queue biến delayed work thành bounded scheduling.
