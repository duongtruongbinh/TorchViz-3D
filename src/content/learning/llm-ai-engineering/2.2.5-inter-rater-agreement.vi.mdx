  title="Tính Cohen kappa"
  contract="observed p_o và expected p_e<1 → κ=(p_o−p_e)/(1−p_e)"
  output="κ=(0.8−0.52)/(1−0.52)=0.5833"
  pitfall="p_e=1 làm denominator bằng 0 và kappa không xác định."
  takeaway="Kappa đo agreement vượt chance, không đo annotator có đúng hay không."
>

`κ = (p_o - p_e)/(1-p_e) = (0.8-0.52)/(1-0.52) = 0.5833`.

```python
def cohen_kappa(observed: float, expected: float) -> float:
    if not 0 <= observed <= 1 or not 0 <= expected < 1:
        raise ValueError('agreements must satisfy 0<=observed<=1 and 0<=expected<1')
    return (observed - expected) / (1 - expected)

assert abs(cohen_kappa(0.8, 0.52) - 7 / 12) < 1e-12
try:
    cohen_kappa(0.8, 1.0)
except ValueError:
    pass
else:
    raise AssertionError('expected agreement of one makes kappa undefined')
```
