## Confusion table

Hai annotator chấm 10 case bằng `pass/fail`:

| | B pass | B fail |
|---|---:|---:|
| A pass | 5 | 1 |
| A fail | 1 | 3 |

Observed agreement dùng đường chéo: `(5+3)/10=0.8`.

## Tính observed/chance agreement

A chọn pass `6/10`, fail `4/10`; B cũng chọn pass `6/10`, fail `4/10`. Chance agreement:

`p_e = 0.6×0.6 + 0.4×0.4 = 0.52`.

Điều chỉnh chance quan trọng khi một nhãn chiếm đa số: observed agreement cao có thể xuất hiện chỉ vì cả hai gần như luôn chọn nhãn đó.

## Tính Cohen kappa

`κ = (p_o - p_e)/(1-p_e) = (0.8-0.52)/(1-0.52) = 0.5833`.

```python
def cohen_kappa(observed: float, expected: float) -> float:
    if not 0 <= observed <= 1 or not 0 <= expected < 1:
        raise ValueError('agreements must satisfy 0<=observed<=1 and 0<=expected<1')
    return (observed - expected) / (1 - expected)

assert abs(cohen_kappa(0.8, 0.52) - 7 / 12) < 1e-12
try:
    cohen_kappa(0.8, 1.0)
except ValueError:
    pass
else:
    raise AssertionError('expected agreement of one makes kappa undefined')
```
