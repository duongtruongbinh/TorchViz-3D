## Token → ID chỉ là lookup

**Input:** `list[str]` gồm `T` tokens.  
**Output:** `list[int]` gồm đúng `T` token IDs.

<LessonNote>**Lỗi thường gặp:** coi ID là vị trí của token trong câu. ID chọn một mục trong vocabulary; sequence position là một trục khác.</LessonNote>

**Handoff:** Đóng gói lookup hai chiều thành `encode` và `decode`.

<TokenizerCodeWalkthrough content={{
  lead: {vi: 'Encode dùng token -> ID; decode dùng inverse mapping ID -> token. Cả hai chiều phải dùng cùng một vocabulary.'},
  diagram: {
    inputText: '\"Linh builds AI.\"',
    outputLabel: {vi: 'Round trip qua cùng vocabulary'},
    tokens: ['text', '→', '[2, 3, 1, 0]', '→', 'text'],
  },
  code: [
    'id_to_token = {',
    '    token_id: token',
    '    for token, token_id in base_vocab.items()',
    '}',
    '',
    'def encode(text: str) -> list[int]:',
    '    return [base_vocab[token] for token in tokenize(text)]',
    '',
    'def decode(token_ids: list[int]) -> str:',
    '    tokens = [id_to_token[token_id] for token_id in token_ids]',
    '    return \" \".join(tokens).replace(\" .\", \".\")',
    '',
    'ids = encode(\"Linh builds AI.\")',
    'assert ids == [2, 3, 1, 0]',
    'assert decode(ids) == \"Linh builds AI.\"',
  ],
  output: ['ids = [2, 3, 1, 0]', 'decoded = \"Linh builds AI.\"'],
  takeaway: {vi: 'Encode có thể thất bại với token ngoài toy vocabulary; decode có thể thất bại với ID không tồn tại. Tokenizer production xử lý theo special-token hoặc byte-fallback contract riêng.'},
}} />

<LessonNote>**Lỗi thường gặp:** yêu cầu `decode(encode(text))` giữ mọi whitespace byte-for-byte dù tokenizer toy đã normalization. Contract ở đây round trip về text đã chuẩn hóa.</LessonNote>
