Llama là model family/weights; Ollama, NIM, Together hoặc self-hosted server quyết định wire API và operational behavior.

**Input:** Exact model card/version/license plus chosen serving runtime.

**Output:** Deployment manifest and normalized inference contract.

**Data/type/shape:** Same logical model may expose Chat Completions, Responses or runtime-native fields; tokenizer/template must match weights.

<CodeLessonFrame title="Worked fixture" contract="typed input → validated output" pitfall="Giữ explicit error path, timeout/cancellation và provider-specific invariant." takeaway="Fixture materialize contract thành artifact deterministic có thể test.">

Manifest lưu weight revision, tokenizer, chat template, quantization và runtime version. Đổi host mà không conformance-test tool roles/stop tokens có thể đổi output.

~~~json
{
  "weights": { "family": "llama", "revision": "pinned-revision", "quantization": "artifact-specific" },
  "tokenizer": { "revision": "same-as-weights", "chatTemplate": "pinned-template-v2" },
  "license": { "documentVersion": "reviewed-version", "approvedUseCase": "support-read-only" },
  "runtime": { "name": "chosen-server", "version": "pinned-version" },
  "contract": { "streamEvents": "internal-v1", "toolCalls": "conformance-tested", "stopMapping": "tested" }
}
~~~

Conformance gate chạy cùng text/tool/stop fixtures trên artifact cũ và mới. Chỉ promote nếu normalized result, safety gates và latency SLO đều đạt.

<LessonNote>Manifest cố ý không hard-code một model alias đang biến động. Điền exact identifiers từ model card, license và runtime ở thời điểm release.</LessonNote>
