## Vì sao cần kiến thức này?

Console hữu ích để khám phá nhưng một lần chạy thủ công không phải evidence production.

**Input:** Prompt version, model capability, schema, parameters và eval fixtures.

**Output:** Saved/exported configuration cùng code có thể chạy lại và kết quả được đưa vào eval.

**Data/type/shape:** UI settings phải được materialize thành request fields; model alias/capability được kiểm tra tại ngày chạy.

## Worked example và contract

Chạy ba fixture ID cố định, lưu prompt/model/schema versions, ngày kiểm tra và
acceptance metric. Console chỉ là nơi thử; artifact chuyển giao là manifest có
thể dựng lại request và nối vào eval harness. Không copy API key hoặc kết luận
từ một output đẹp.

<LessonNote>Chỉ đưa artifact có thể kiểm chứng vào output/log; không yêu cầu hoặc lưu hidden chain-of-thought.</LessonNote>

## Production pitfalls và handoff

**Sai lầm thường gặp:**

- Quên temperature/tool/schema khi chuyển sang code.
- Dùng alias biến động như fixture vĩnh viễn.
- Paste dữ liệu production nhạy cảm vào console.

~~~ts
import assert from "node:assert/strict";

type ExperimentSpec = {
  id: string;
  promptVersion: string;
  modelId: string;
  schemaVersion: string;
  evalSuiteVersion: string;
  checkedOn: string;
  fixtureIds: readonly string[];
  maxOutputTokens: number;
};

function toOpenAIExperiment(spec: ExperimentSpec) {
  if (!/^\d{4}-\d{2}-\d{2}$/.test(spec.checkedOn)) throw new Error("invalid_date");
  if (spec.fixtureIds.length === 0) throw new Error("empty_fixture_set");
  if (!Number.isInteger(spec.maxOutputTokens) || spec.maxOutputTokens <= 0) {
    throw new Error("invalid_output_budget");
  }
  return {
    provider: "openai" as const,
    apiSurface: "Responses API",
    experimentId: spec.id,
    promptVersion: spec.promptVersion,
    modelId: spec.modelId,
    schemaVersion: spec.schemaVersion,
    evalSuiteVersion: spec.evalSuiteVersion,
    checkedOn: spec.checkedOn,
    requestShape: {
      instructionsFrom: spec.promptVersion,
      inputFixtureIds: [...spec.fixtureIds],
      structuredOutputSchema: spec.schemaVersion,
      maxOutputTokens: spec.maxOutputTokens,
    },
  };
}

const spec: ExperimentSpec = {
  id: "support-exp-17",
  promptVersion: "support-v12",
  modelId: "configured-model-id",
  schemaVersion: "support-v4",
  evalSuiteVersion: "policy-set-7",
  checkedOn: "2026-07-23",
  fixtureIds: ["ticket-01", "ticket-02", "ticket-03"],
  maxOutputTokens: 300,
};
const result = toOpenAIExperiment(spec);
assert.equal(result.apiSurface, "Responses API");
assert.deepEqual(result.requestShape.inputFixtureIds, [
  "ticket-01", "ticket-02", "ticket-03",
]);
assert.equal("apiKey" in result, false);
assert.throws(
  () => toOpenAIExperiment({ ...spec, fixtureIds: [] }),
  /empty_fixture_set/,
);
~~~

<LessonNote>Đây là manifest cục bộ, không phải provider call. Nguồn official

Model, controls và console behavior phải kiểm tra lại tại thời điểm chạy.</LessonNote>
