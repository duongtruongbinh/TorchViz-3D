## Claim contract

Tách response thành atomic claims. Mỗi claim có `{text, evidence_ids, supported, severity}`. Evidence scope phải được khai báo: retrieved context, reference database hoặc nguồn đã xác minh. Citation format đúng không tự chứng minh claim được hỗ trợ.

Case không có evidence cần expected `abstain`; đo overconfidence riêng.

## Tính support rate

Response có bốn claims; ba claims supported, một unsupported:

`support_rate = 3/4 = 0.75`, `unsupported_rate = 1/4 = 0.25`.

Không tính câu chào hoặc style fragment thành claim để làm denominator lớn giả tạo. Claim splitter và annotation policy phải được version.

## Severity-weighted score

Gán weight: low `1`, high `4`. Ba supported claims có tổng weight `6`; unsupported high-severity claim weight `4`:

`weighted_support = 6/(6+4)=0.6`.

```python
def weighted_support(weights: list[int], supported: list[bool]) -> float:
    if not weights or len(weights) != len(supported):
        raise ValueError('weights and labels must be non-empty and aligned')
    if any(isinstance(weight, bool) or not isinstance(weight, int) or weight <= 0 for weight in weights):
        raise ValueError('weights must be positive integers')
    if any(not isinstance(label, bool) for label in supported):
        raise TypeError('supported labels must be booleans')
    return sum(weight for weight, ok in zip(weights, supported) if ok) / sum(weights)

weights = [2, 2, 2, 4]
supported = [True, True, True, False]
score = weighted_support(weights, supported)
assert score == 0.6
assert 0.0 <= score <= 1.0
try:
    weighted_support([2, 4], [True])
except ValueError:
    pass
else:
    raise AssertionError('misaligned claim labels must fail')
```

## Invariants

Không để unsupported critical claim bị average che lấp; thêm critical count/gate. Giữ claim-to-evidence mapping, nhưng redact private content trong artifact. Đo factuality cùng answer relevance và abstention để tránh “luôn từ chối” đạt score giả.

Application Quiz kế tiếp dùng các signal này để phân biệt retrieval và generation failure trong RAG.
