  contract="positive integer weights aligned với boolean support labels"
  output="supported weight 6 / total weight 10 = 0.6"
  pitfall="Unsupported high-severity claim không nên bị nhiều low-severity claims che lấp."

Gán weight: low `1`, high `4`. Ba supported claims có tổng weight `6`; unsupported high-severity claim weight `4`:

`weighted_support = 6/(6+4)=0.6`.

```python
def weighted_support(weights: list[int], supported: list[bool]) -> float:
    if not weights or len(weights) != len(supported):
        raise ValueError('weights and labels must be non-empty and aligned')
    if any(isinstance(weight, bool) or not isinstance(weight, int) or weight <= 0 for weight in weights):
        raise ValueError('weights must be positive integers')
    if any(not isinstance(label, bool) for label in supported):
        raise TypeError('supported labels must be booleans')
    return sum(weight for weight, ok in zip(weights, supported) if ok) / sum(weights)

weights = [2, 2, 2, 4]
supported = [True, True, True, False]
score = weighted_support(weights, supported)
assert score == 0.6
assert 0.0 <= score <= 1.0
try:
    weighted_support([2, 4], [True])
except ValueError:
    pass
else:
    raise AssertionError('misaligned claim labels must fail')
```
