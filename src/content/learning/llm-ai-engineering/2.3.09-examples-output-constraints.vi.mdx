## Examples phải thỏa parser

Example chỉ hữu ích khi output của nó tuân cùng contract mà production parser chấp nhận. Nếu schema bắt buộc `category` và `confidence`, demonstration thiếu `confidence` phải bị reject hoặc migrate, không được dạy model một format chết.

**Input:** versioned schema, positive/negative fixtures và refusal/incomplete policy.

**Output:** một discriminated union đã validate; missing/extra field, enum sai hoặc bound sai trở thành typed error.

## Parser có các nhánh rõ

~~~ts
import assert from "node:assert/strict";

type Category = "billing" | "delivery" | "other";
type TicketOutput =
  | { kind: "decision"; category: Category; confidence: number }
  | { kind: "refusal"; code: "policy" }
  | { kind: "incomplete"; code: "max_output" };

function hasExactKeys(record: Record<string, unknown>, keys: readonly string[]): boolean {
  return Object.keys(record).sort().join(",") === [...keys].sort().join(",");
}

function parseTicketOutput(raw: string): TicketOutput {
  let value: unknown;
  try {
    value = JSON.parse(raw);
  } catch {
    throw new Error("invalid_json");
  }
  if (!value || typeof value !== "object" || Array.isArray(value)) {
    throw new Error("invalid_output_shape");
  }
  const record = value as Record<string, unknown>;
  if (record.kind === "decision") {
    if (!hasExactKeys(record, ["kind", "category", "confidence"])) {
      throw new Error("decision_fields_mismatch");
    }
    const categories: readonly unknown[] = ["billing", "delivery", "other"];
    if (!categories.includes(record.category)) throw new Error("invalid_category");
    if (typeof record.confidence !== "number" || record.confidence < 0 || record.confidence > 1) {
      throw new Error("invalid_confidence");
    }
    return {
      kind: "decision",
      category: record.category as Category,
      confidence: record.confidence,
    };
  }
  if (record.kind === "refusal" && hasExactKeys(record, ["kind", "code"]) && record.code === "policy") {
    return { kind: "refusal", code: "policy" };
  }
  if (record.kind === "incomplete" && hasExactKeys(record, ["kind", "code"]) && record.code === "max_output") {
    return { kind: "incomplete", code: "max_output" };
  }
  throw new Error("unknown_output_branch");
}

assert.deepEqual(
  parseTicketOutput('{"kind":"decision","category":"delivery","confidence":0.9}'),
  { kind: "decision", category: "delivery", confidence: 0.9 },
);
assert.deepEqual(
  parseTicketOutput('{"kind":"refusal","code":"policy"}'),
  { kind: "refusal", code: "policy" },
);
assert.throws(
  () => parseTicketOutput('{"kind":"decision","category":"delivery"}'),
  /decision_fields_mismatch/,
);
assert.throws(
  () => parseTicketOutput('{"kind":"decision","category":"ship","confidence":0.9}'),
  /invalid_category/,
);
assert.throws(
  () => parseTicketOutput('{"kind":"decision","category":"delivery","confidence":0.9,"rawTicket":"secret"}'),
  /decision_fields_mismatch/,
);
~~~

## Production gate

- Run chính parser trên mọi candidate example trong CI.
- Version schema và examples cùng nhau; migrate hoặc xóa artifact cũ khi field đổi.
- Phân biệt refusal, incomplete và invalid để retry/fallback đúng nguyên nhân, có giới hạn.
- Không dùng `as DomainType` thay runtime validation.
- Log branch/error code và schema version; không log raw output chứa PII, secret hoặc hidden chain-of-thought.

**Kết nối:** Quiz kiểm tra positive constraints, boundaries và validation.
