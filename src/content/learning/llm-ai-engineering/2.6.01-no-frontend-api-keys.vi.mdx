**Pitfalls:**

- Prefix key bằng `VITE_`/`NEXT_PUBLIC_`.
- Đặt key trong mobile/web bundle rồi obfuscate.
- Cho browser gọi provider proxy mở không auth.

<LessonNote>Không bao giờ log credential, raw prompt/response hoặc identifier nhạy cảm một cách vô điều kiện.</LessonNote>

Nếu scan phát hiện key thật, block release chưa đủ: đánh giá exposure, revoke/rotate, kiểm tra usage bất thường và ghi incident timeline. Xóa chuỗi khỏi source không thu hồi credential đã lộ.

**Kết nối:** Secret lifecycle khác giữa local `.env` và production secret manager.
