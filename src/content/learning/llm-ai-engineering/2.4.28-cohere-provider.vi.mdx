Retrieval pipeline dùng embeddings/index rồi rerank candidates; generation chỉ nhận top evidence. Structured tool output dùng current V2 controls và validator.

| Capability | Wire output cần giữ | Conformance check |
|---|---|---|
| Chat V2 | Ordered content, finish reason, usage | Text/refusal/terminal mapping |
| Tool use | Call ID, name, untrusted arguments | Schema + authorization + result loop |
| Structured output | Provider control + local validation | Required/enum/additional fields |
| Embeddings | `(N,D)`, model/revision, usage | Count/dimension before upsert |
| Rerank | Candidate index + relevance score | Index bounds và stable document mapping |

<LessonNote>Rerank không tạo embedding và JSON syntax không tự bảo đảm schema. Chỉ bật capability đã được official docs và fixture của exact API version xác nhận.</LessonNote>
