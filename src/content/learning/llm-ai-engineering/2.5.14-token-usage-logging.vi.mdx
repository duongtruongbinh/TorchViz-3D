Log `{modelClass:'fast',inputTokens:420,outputTokens:80,status:'completed',subject:'...'}`; không log ticket. Alert trên cost/subject và estimate delta.

~~~ts
import assert from "node:assert/strict";
import { createHmac } from "node:crypto";

function pseudonym(secret: string, scope: string, internalId: string): string {
  return createHmac("sha256", secret)
    .update(`${scope}\0${internalId}`)
    .digest("hex")
    .slice(0, 24);
}

const event = {
  schemaVersion: 2,
  keyVersion: "observability-key-v3",
  subject: pseudonym("fixture-secret-only", "support-api", "internal-user-17"),
  modelClass: "fast",
  status: "completed",
  inputTokens: 420,
  outputTokens: 80,
  estimatedInputTokens: 400,
  latencyMs: 730,
};
assert.equal(event.inputTokens - event.estimatedInputTokens, 20);
assert.equal(event.subject.length, 24);
assert.equal(JSON.stringify(event).includes("internal-user-17"), false);
assert.deepEqual(
  Object.keys(event).filter(key => ["prompt", "response", "apiKey", "email"].includes(key)),
  [],
);
~~~
<LessonNote>Plain SHA-256 của email/user ID entropy thấp vẫn dò và liên kết được. HMAC key ở secret manager, có scope/key version/rotation; log có access, sampling và retention policy.</LessonNote>

- Log API key hoặc raw prompt.
