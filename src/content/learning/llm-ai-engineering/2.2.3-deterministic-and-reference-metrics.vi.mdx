## Contract và normalization

Exact match chỉ có nghĩa sau một normalization đã version: Unicode/case/whitespace/punctuation có được đổi hay không. Structured output nên parse và validate schema trước khi chấm semantics; parse failure là result riêng, không phải empty answer.

Với token/set labels, lưu `prediction` và `reference` thành collections rõ ràng để tính `TP`, `FP`, `FN`.

</MdxPage>

## Tính precision/recall/F1

Reference facts `{a,b,c,d}`, prediction `{a,b,x}`:

- `TP=2` (`a,b`), `FP=1` (`x`), `FN=2` (`c,d`).
- precision `=2/(2+1)=2/3`.
- recall `=2/(2+2)=1/2`.
- F1 `=2PR/(P+R)=4/7≈0.5714`.

Nếu cả prediction và reference rỗng, policy phải định nghĩa score; không chia `0/0` im lặng.

</MdxPage>

## Deterministic implementation

```python
def set_prf(prediction: set[str], reference: set[str]) -> tuple[float, float, float]:
    tp = len(prediction & reference)
    fp = len(prediction - reference)
    fn = len(reference - prediction)
    precision = tp / (tp + fp) if tp + fp else 1.0
    recall = tp / (tp + fn) if tp + fn else 1.0
    f1 = 2 * precision * recall / (precision + recall) if precision + recall else 0.0
    return precision, recall, f1

p, r, f1 = set_prf({'a', 'b', 'x'}, {'a', 'b', 'c', 'd'})
assert abs(p - 2 / 3) < 1e-12
assert abs(r - 1 / 2) < 1e-12
assert abs(f1 - 4 / 7) < 1e-12
assert set_prf(set(), {'a'}) == (1.0, 0.0, 0.0)
assert set_prf(set(), set()) == (1.0, 1.0, 1.0)
```

Fixture này chọn convention `both-empty = 1`; production spec phải ghi rõ convention này để hai harness không chấm khác nhau.

## Invariants và handoff

Assert score nằm trong `[0,1]`, normalization không thay nghĩa và fixture cố định cho edge cases. Overlap cao vẫn có thể chứa claim sai; metric deterministic phải đi cùng rubric/judge khi output mở.
