## Contract trước khi viết code

Với `ids`, `max_length=T` và `stride`, Dataset phải trả:

```text
x: (T,), torch.long
y: (T,), torch.long
x[1:] == y[:-1]
```

DataLoader gom các sample thành:

```text
x_batch, y_batch: (B,T)
```

Tokenizer/vocabulary đã được cố định ở các bài trước. Lesson này không dựng vocabulary mới từ validation data.

<LessonNote>**Lỗi thường gặp:** để DataLoader chịu trách nhiệm shift target. DataLoader chỉ collate các cặp mà Dataset trả về.</LessonNote>

**Handoff:** Dataset sẽ materialize từng cặp input/target.

</MdxPage>

## Dataset sliding-window tối thiểu

```python
import torch
from torch.utils.data import Dataset, DataLoader

class GPTDatasetV1(Dataset):
    def __init__(self, ids, max_length, stride):
        self.inputs = []
        self.targets = []

        for start in range(0, len(ids) - max_length, stride):
            chunk = ids[start:start + max_length + 1]
            self.inputs.append(torch.tensor(chunk[:-1], dtype=torch.long))
            self.targets.append(torch.tensor(chunk[1:], dtype=torch.long))

    def __len__(self):
        return len(self.inputs)

    def __getitem__(self, index):
        return self.inputs[index], self.targets[index]
```

<LessonNote>**Lỗi thường gặp:** slice source chỉ đến `start+T`; khi đó `chunk[1:]` chỉ dài `T-1`.</LessonNote>

**Handoff:** Dùng đúng fixed ID sequence của running example.

</MdxPage>

## Tạo Dataset từ running IDs

```python
ids = [2, 3, 1, 0, 5, 2, 4, 1, 0]

dataset = GPTDatasetV1(
    ids,
    max_length=3,
    stride=2,
)

assert len(dataset) == 3

x0, y0 = dataset[0]
assert x0.tolist() == [2, 3, 1]
assert y0.tolist() == [3, 1, 0]
assert torch.equal(x0[1:], y0[:-1])
```

Trong training thật, `ids` phải đến từ train split đã tách trước. Validation split dùng cùng tokenizer nhưng một `GPTDatasetV1` riêng.

<LessonNote>**Lỗi thường gặp:** encode train/validation bằng hai vocabularies khác nhau. Cùng integer ID khi đó không còn trỏ cùng token.</LessonNote>

## DataLoader gom sample thành batch

```python
loader = DataLoader(
    dataset,
    batch_size=2,
    shuffle=False,
    drop_last=False,
)

input_ids, target_ids = next(iter(loader))

assert input_ids.shape == target_ids.shape == (2, 3)
assert input_ids.dtype == target_ids.dtype == torch.long
```

`shuffle=False` làm smoke test deterministic. Khi training, `shuffle=True` đổi thứ tự samples nhưng không thay token order bên trong mỗi sample.

Batch size nhỏ dùng ít memory hơn; batch size lớn xử lý nhiều windows song song hơn. Đây là hyperparameter của DataLoader/training, không phải vocabulary hay context length.

<LessonNote>**Lỗi thường gặp:** shuffle token positions trong mỗi row. Next-token target chỉ hợp lệ khi sequence order được giữ nguyên.</LessonNote>

## Smoke test giá trị và shape

```python
expected_x = torch.tensor([
    [2, 3, 1],
    [1, 0, 5],
])
expected_y = torch.tensor([
    [3, 1, 0],
    [0, 5, 2],
])

assert torch.equal(input_ids, expected_x)
assert torch.equal(target_ids, expected_y)
assert torch.equal(input_ids[:, 1:], target_ids[:, :-1])

print(input_ids.shape)  # torch.Size([2, 3])
```

Ba invariants trước khi train:

1. input và target cùng `(B,T)`;
2. target dịch đúng một token;
3. dtype là integer index (`torch.long`).

<LessonNote>**Handoff:** Batch IDs đã sẵn sàng tra bảng token embedding và thêm positional information.</LessonNote>
