  contract="controlled small runs → fitted curve → budget choice → intermediate validation"
  output="ScaleRun ghi N, D, compute FLOPs và validation loss"
  pitfall="Đổi mạnh data mixture, tokenizer, optimizer, context length hoặc architecture có thể buộc fit lại."

>

1. Huấn luyện nhiều model nhỏ ở các mức `N`, `D` và `C`.
2. Giữ tokenizer, data recipe, architecture family và evaluation protocol đủ nhất quán.
3. Fit scaling curve cho validation/test loss.
4. Chọn cấu hình hứa hẹn nhất dưới budget.
5. Chạy model trung gian trước final run.

```ts
type ScaleRun = {
  parameters: number;
  trainingTokens: number;
  computeFlops: number;
  validationLoss: number;
};
```
