## Hai contracts

Pointwise tạo `{criterion_scores, critical_flags}` cho từng response và phù hợp với absolute gate. Pairwise tạo `A|B|tie` cho cùng case và phù hợp chọn candidate. Một model có thể thắng pairwise nhưng vẫn fail absolute safety gate.

Pairwise input phải ẩn model identity, chuẩn hóa format và cho phép tie.

</MdxPage>

## Pairwise matrix

Trên 20 case: candidate thắng 10, baseline thắng 6, tie 4. Với half-tie convention:

`candidate_score = (10 + 0.5×4)/20 = 0.60`.

Strict win rate không tính tie là `10/(10+6)=0.625`; báo rõ convention thay vì trộn hai số.

## Tính win rate

```python
def pairwise_score(wins: int, losses: int, ties: int) -> float:
    counts = (wins, losses, ties)
    if any(isinstance(count, bool) or not isinstance(count, int) for count in counts):
        raise TypeError('counts must be integers')
    if min(wins, losses, ties) < 0 or wins + losses + ties == 0:
        raise ValueError('counts must be non-negative and non-empty')
    return (wins + 0.5 * ties) / (wins + losses + ties)

assert pairwise_score(10, 6, 4) == 0.6
assert pairwise_score(0, 0, 2) == 0.5
for invalid in [(0, 0, 0), (1, -1, 0)]:
    try:
        pairwise_score(*invalid)
    except ValueError:
        pass
    else:
        raise AssertionError('invalid counts must fail')
```

Chạy cả order `candidate=A` và `candidate=B`; một winner đổi theo vị trí là disagreement signal.

## Invariants

Mỗi case phải có đúng một outcome, counts cộng thành sample size và results giữ case ID/order assignment. Báo score theo slice và confidence interval; không dùng pairwise win để bỏ qua must-pass pointwise criteria.
