## Một sample dài T cần T+1 corpus tokens

Corpus đã encode:

```text
ids = [2, 3, 1, 0, 5, 2, 4, 1, 0]
```

Chọn `context_length=T=3`, `stride=2`. Để tạo input và target đều dài 3, cửa sổ nguồn đầu tiên phải chứa 4 token:

```text
chunk = [2, 3, 1, 0]
```

**Input của bước:** một dãy corpus IDs dài `N=9`.  
**Output của mỗi sample:** hai dãy integer cùng shape `(T,)`.

<LessonNote>**Lỗi thường gặp:** lấy đúng T corpus tokens rồi cố tạo T next-token targets. Target cuối cần thêm một token ở bên phải.</LessonNote>

**Handoff:** Hai slice lệch nhau đúng một vị trí.

</MdxPage>

## Input và target lệch một token

Từ chunk đầu:

```text
input  = [2, 3, 1]
target = [3, 1, 0]
```

Ba bài toán next-token nằm trên cùng một hàng:

```text
2 -> 3
3 -> 1
1 -> 0
```

Invariant kiểm tra shift:

```python
assert input[1:] == target[:-1]
```

<LessonNote>**Lỗi thường gặp:** copy input thành target. Khi đó model chỉ bị yêu cầu lặp lại token hiện tại, không dự đoán token kế tiếp.</LessonNote>

**Handoff:** `stride` quyết định điểm bắt đầu của sample tiếp theo, không thay đổi quy tắc shift này.

</MdxPage>

## Stride điều khiển overlap

Với `range(0, N-T, stride)`:

```text
N=9, T=3, stride=2
start positions = [0, 2, 4]
```

Ba sample hợp lệ:

```text
[2,3,1] -> [3,1,0]
[1,0,5] -> [0,5,2]
[5,2,4] -> [2,4,1]
```

`stride=1` tạo nhiều overlap hơn; `stride=T` làm các input windows không overlap. Start `6` không hợp lệ vì target slice sẽ cần corpus index `9`, nằm ngoài dãy.

<LessonNote>**Lỗi thường gặp:** dùng `N/T` để đếm windows. Số sample phụ thuộc cả token target bổ sung và stride.</LessonNote>

**Handoff:** Dataset trả từng cặp `(T,)`; DataLoader mới gom chúng thành batch.

</MdxPage>

## DataLoader thêm batch dimension

Gom hai sample đầu:

```text
input_ids  = [[2,3,1],
              [1,0,5]]

target_ids = [[3,1,0],
              [0,5,2]]
```

Cả hai tensor có shape `(B,T)=(2,3)`.

Batch size `B` lớn hơn cho nhiều sample chạy song song nhưng dùng nhiều activation memory hơn. `B` không thay đổi context length `T`, và DataLoader không tự tạo shifted targets.

<LessonNote>**Lỗi thường gặp:** nhầm `(B,T)` với `(T,B)`. Convention của khóa học đặt batch trước, sequence sau.</LessonNote>

**Handoff:** Trước khi viết Dataset, phải đặt train/validation boundary đúng chỗ.

</MdxPage>

## Split tài liệu trước, tạo windows sau

Sai:

```text
toàn bộ corpus -> overlapping windows -> random split windows
```

Hai windows gần nhau có thể chia sẻ phần lớn token nhưng rơi vào hai split, làm validation nhìn thấy gần như cùng context với training.

Đúng:

```text
documents -> train/validation split
          -> encode mỗi split bằng cùng tokenizer
          -> tạo windows riêng trong từng split
```

Document boundary có thể nằm trong một split, nhưng một training window không được cắt xuyên sang validation corpus.

<LessonNote>**Lỗi thường gặp:** nghĩ shuffle sau khi tạo windows loại được leakage. Shuffle chỉ đổi thứ tự; nó không xóa token overlap giữa hai split.</LessonNote>

**Handoff:** Quiz kiểm tra các contract trước khi ta viết `Dataset` và `DataLoader`.

</MdxPage>
