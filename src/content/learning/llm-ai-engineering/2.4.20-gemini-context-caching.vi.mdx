Prefix 20k token dùng 10 lần; explicit-cache setup chỉ đáng giá nếu supported và savings vượt create/storage overhead. Update policy v13 phải tạo key mới.

~~~ts
import assert from "node:assert/strict";
type CacheEconomics = {
  uncachedPerUse: number;
  cachedPerUse: number;
  createAndStorage: number;
  reuseCount: number;
};
function compare(cost: CacheEconomics) {
  const withoutCache = cost.uncachedPerUse * cost.reuseCount;
  const withCache = cost.createAndStorage + cost.cachedPerUse * cost.reuseCount;
  return {
    withoutCache,
    withCache,
    savings: withoutCache - withCache,
    useCache: withCache < withoutCache,
  };
}

const economics = compare({
  uncachedPerUse: 20_000,
  cachedPerUse: 2_000,
  createAndStorage: 25_000,
  reuseCount: 10,
});
assert.deepEqual(economics, {
  withoutCache: 200_000,
  withCache: 45_000,
  savings: 155_000,
  useCache: true,
});
const cacheKeyParts = ["tenant-a", "model-revision", "prefix-hash", "schema-v2", "policy-v13"];
assert.equal(new Set(cacheKeyParts).size, 5);
~~~
<LessonNote>Đơn vị ở đây là cost-weighted token units để minh họa break-even, không phải giá provider. Dùng pricing/capability hiện hành và scope cache theo tenant/policy.</LessonNote>
