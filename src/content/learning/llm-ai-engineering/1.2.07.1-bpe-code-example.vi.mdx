## Bước 2: Tạo BPE tokenizer

<TokenizerCodeWalkthrough content={{
  lead: {vi: 'Trước khi train, ta tạo tokenizer và gắn hai thành phần xử lý text: pre-tokenizer dùng trước khi BPE chạy và decoder dùng khi ghép token trở lại.'},
  diagram: {
    inputText: 'Tokenizer',
    outputLabel: {vi: 'Ba thành phần chính'},

  },
  code: [
    'from tokenizers import Tokenizer',
    'from tokenizers.decoders import BPEDecoder',
    'from tokenizers.models import BPE',
    'from tokenizers.pre_tokenizers import Whitespace',
    'from tokenizers.trainers import BpeTrainer',
    '',
    'corpus = [',
    '    "learn learner learning",',
    '    "learn learning",',
    '    "learner learns",',
    ']',

    'print("Số câu:", len(corpus))',
    'print("Câu đầu:", corpus[0])',
    '',
    'tokenizer = Tokenizer(BPE(unk_token="[UNK]"))',
    'tokenizer.pre_tokenizer = Whitespace()',
    'tokenizer.decoder = BPEDecoder(suffix="</w>")',
  ],
  dimmedLineCount: 14,
  output: [],
}} />

- `Tokenizer(BPE(unk_token="[UNK]"))`: tạo một tokenizer mới, chọn BPE làm thuật toán học token và dùng `[UNK]` cho nội dung không có trong vocabulary.
- `Whitespace()`: tách `learner learning` thành hai từ `learner` và `learning` trước khi BPE học các mảnh nhỏ hơn.
- `BPEDecoder(suffix="</w>")`: khi decode, bỏ dấu `</w>` ở cuối từ và khôi phục khoảng cách trước từ tiếp theo. `</w>` chỉ là dấu đánh dấu, không phải ký tự whitespace thật.

## Bước 3: Cấu hình và train BPE

<TokenizerCodeWalkthrough content={{
  lead: {vi: '`BpeTrainer` chứa các giới hạn và quy ước training. Sau khi cấu hình xong, ta truyền cả corpus và trainer vào tokenizer để bắt đầu học vocabulary.'},
  diagram: {
    inputText: 'BpeTrainer',
    outputLabel: {vi: 'Thiết lập cho quá trình training'},
    tokens: ['V = 20', 'min = 2', '</w>', 'special tokens'],
  },
  code: [
    'from tokenizers import Tokenizer',
    'from tokenizers.decoders import BPEDecoder',
    'from tokenizers.models import BPE',
    'from tokenizers.pre_tokenizers import Whitespace',
    'from tokenizers.trainers import BpeTrainer',
    '',
    'corpus = [',
    '    "learn learner learning",',
    '    "learn learning",',
    '    "learner learns",',
    ']',
    '',
    'print("Số câu:", len(corpus))',
    'print("Câu đầu:", corpus[0])',
    '',
    'tokenizer = Tokenizer(BPE(unk_token="[UNK]"))',
    'tokenizer.pre_tokenizer = Whitespace()',
    'tokenizer.decoder = BPEDecoder(suffix="</w>")',
    '',
    'trainer = BpeTrainer(',
    '    vocab_size=20,',
    '    min_frequency=2,',
    '    end_of_word_suffix="</w>",',
    '    special_tokens=["[UNK]", "[PAD]", "[BOS]", "[EOS]"],',
    ')',
    '',
    'tokenizer.train_from_iterator(corpus, trainer=trainer)',
  ],
  dimmedLineCount: 18,
  output: [],
}} />

- `BpeTrainer(...)`: chứa các thiết lập sẽ được dùng trong lúc huấn luyện tokenizer.
- `vocab_size=20`: đặt số lượng token tối đa mà vocabulary có thể chứa là 20.
- `min_frequency=2`: một cặp phải xuất hiện ít nhất hai lần mới được cân nhắc để gộp.
- `end_of_word_suffix="</w>"`: trong lúc chuẩn bị dữ liệu để train BPE, gắn `</w>` vào đơn vị cuối của mỗi từ. Ví dụ: `learner` bắt đầu thành `l e a r n e r</w>`.
- `special_tokens=[...]`: thêm sẵn `[UNK]`, `[PAD]`, `[BOS]` và `[EOS]` vào vocabulary.

</MdxPage>
