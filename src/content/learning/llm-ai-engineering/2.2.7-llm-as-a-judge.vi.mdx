## Typed judge boundary

Judge adapter nhận `case`, `candidate response`, optional `reference/evidence`, rubric version. Nó trả `JudgeResult`; provider text không đi thẳng vào aggregate. Stable case/run IDs được giữ ngoài prompt.

Judge rationale chỉ là concise evidence artifact, không phải hidden chain-of-thought hay ground truth.

## Prompt và output schema

Yêu cầu JSON với đúng:

```json
{"score": 0, "verdict": "pass|fail|review", "evidence": ["criterion: observation"]}
```

Schema/parser kiểm tra structure; rubric kiểm tra semantics. Pairwise protocol phải ẩn identity, swap order và cho phép tie.

## Parser/error contract

Malformed JSON, score ngoài `0..4`, verdict lạ hoặc evidence rỗng đều là `judge_error`, không tự đổi thành fail/pass. Caller có bounded retry cho lỗi transient/schema, sau đó human review hoặc deterministic fallback theo risk.

Không log raw response nếu chứa PII; giữ redacted evidence cùng provider request ID khi policy cho phép.

## Deterministic adapter

```python
from dataclasses import dataclass
import json

@dataclass(frozen=True)
class JudgeResult:
    score: int
    verdict: str
    evidence: tuple[str, ...]

def parse_judge(raw: str) -> JudgeResult:
    value = json.loads(raw)
    if not isinstance(value, dict):
        raise ValueError('judge output must be an object')
    if set(value) != {'score', 'verdict', 'evidence'}:
        raise ValueError('unexpected judge fields')
    score = value['score']
    if isinstance(score, bool) or not isinstance(score, int) or not 0 <= score <= 4:
        raise ValueError('score must be an integer in [0,4]')
    verdict = value['verdict']
    if not isinstance(verdict, str) or verdict not in {'pass', 'fail', 'review'}:
        raise ValueError('invalid verdict')
    evidence = value['evidence']
    if not isinstance(evidence, list) or not evidence or not all(isinstance(x, str) and x.strip() for x in evidence):
        raise ValueError('evidence must be a non-empty string list')
    return JudgeResult(score, verdict, tuple(evidence))

raw = '{"score":3,"verdict":"pass","evidence":["correctness: supported"]}'
assert parse_judge(raw) == JudgeResult(3, 'pass', ('correctness: supported',))
try:
    parse_judge('{"score":9,"verdict":"pass","evidence":["x"]}')
except ValueError as error:
    assert 'score' in str(error)
else:
    raise AssertionError('invalid score must fail closed')
for invalid in [
    '[]',
    '{"score":true,"verdict":"pass","evidence":["x"]}',
    '{"score":3,"verdict":[],"evidence":["x"]}',
]:
    try:
        parse_judge(invalid)
    except ValueError:
        pass
    else:
        raise AssertionError('invalid judge shape/type must fail closed')
```

## Calibration handoff

Đo agreement với human label đã version theo từng language/risk slice; đọc disagreement và đặt escalation rule trước khi mở rộng.
