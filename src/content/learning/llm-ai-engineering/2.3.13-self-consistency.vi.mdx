## Vote chỉ sau normalization

Nhiều samples có thể giảm lỗi ngẫu nhiên nếu có answer extractor và verifier phù hợp, nhưng tăng cost và không sửa lỗi tương quan.

**Input:** cùng task/policy version, fixed sampling config, số candidates `K`, normalizer và minimum agreement.

**Output:** normalized candidate set, winner/agreement hoặc explicit abstain.

Không vote trên raw prose: `"100"`, `"100.00"` và `100` cần về cùng domain value. Agreement là tỷ lệ phiếu trong sample set, không phải calibrated probability.

## Deterministic vote và abstain

~~~ts
import assert from "node:assert/strict";

type VoteResult =
  | { kind: "winner"; value: number; votes: number; agreement: number }
  | { kind: "abstain"; reason: "tie" | "low_agreement" };

function normalizeAmount(value: string | number): number {
  const text = String(value).trim();
  if (!/^[0-9]+(?:\.[0-9]+)?$/.test(text)) throw new Error("invalid_candidate");
  const amount = Number(text);
  if (!Number.isFinite(amount) || !Number.isInteger(amount) || amount < 0) {
    throw new Error("invalid_candidate");
  }
  return amount;
}

function voteAmounts(
  candidates: readonly (string | number)[],
  minimumAgreement: number,
): VoteResult {
  if (candidates.length === 0) throw new Error("empty_candidates");
  if (!(minimumAgreement > 0.5 && minimumAgreement <= 1)) {
    throw new Error("invalid_agreement_threshold");
  }
  const counts = new Map<number, number>();
  for (const raw of candidates) {
    const value = normalizeAmount(raw);
    counts.set(value, (counts.get(value) ?? 0) + 1);
  }
  const ranked = [...counts.entries()].sort((a, b) => b[1] - a[1] || a[0] - b[0]);
  if (ranked.length > 1 && ranked[0][1] === ranked[1][1]) {
    return { kind: "abstain", reason: "tie" };
  }
  const [value, votes] = ranked[0];
  const agreement = votes / candidates.length;
  if (agreement < minimumAgreement) return { kind: "abstain", reason: "low_agreement" };
  return { kind: "winner", value, votes, agreement };
}

assert.deepEqual(voteAmounts([100, "100.00", 80, "100", 80], 0.6), {
  kind: "winner",
  value: 100,
  votes: 3,
  agreement: 0.6,
});
assert.deepEqual(voteAmounts([100, 80], 0.6), { kind: "abstain", reason: "tie" });
assert.deepEqual(voteAmounts([100, 100, 80, 60], 0.6), {
  kind: "abstain",
  reason: "low_agreement",
});
assert.throws(() => voteAmounts([], 0.6), /empty_candidates/);
assert.throws(() => voteAmounts(["100 VND"], 0.6), /invalid_candidate/);
~~~

## Từ sampling đến bounded search

Independent sampling phù hợp khi cần nhiều cách giải cùng một trạng thái rồi vote. Bounded tree search chỉ đáng thử khi task có:

- lựa chọn **tuần tự** tạo candidate states kiểm chứng được;
- branching factor và `maxNodes`/deadline hữu hạn;
- scorer độc lập, terminal condition và tie/abstain rule;
- cache/dedup để không mở lại cùng state.

Không có các contract này, “tree” chỉ nhân số model calls và tạo selection bias. Dù dùng vote hay search, candidate cuối vẫn phải qua verifier; cap cost/deadline và không log hidden reasoning.
