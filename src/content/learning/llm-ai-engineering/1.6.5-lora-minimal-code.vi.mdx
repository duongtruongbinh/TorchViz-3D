## Contract của LoRA linear

**Mục tiêu:** Bọc một `nn.Linear(d_in,d_out)` sao cho base weight bị đóng băng, output shape không đổi và chỉ A/B trainable.

Input có shape `(...,d_in)`; cả base branch và LoRA branch trả `(...,d_out)`. Adapter ban đầu phải tạo update 0 để wrapper khớp layer gốc trước training.

<LessonNote>Đây là implementation giáo dục. Thư viện PEFT thực tế còn quản lý target modules, adapter state, quantization và merge/unmerge an toàn.</LessonNote>

**Takeaway:** LoRA là một nhánh cộng thêm, không thay contract của linear.

## Hai ma trận hạng thấp

```python
import torch
from torch import nn

class LoRAAdapter(nn.Module):
    def __init__(self, d_in, d_out, rank=4, alpha=8.0):
        super().__init__()
        if d_in <= 0 or d_out <= 0:
            raise ValueError("d_in and d_out must be positive")
        if not isinstance(rank, int) or not 0 < rank <= min(d_in, d_out):
            raise ValueError("rank must be an integer in [1, min(d_in,d_out)]")
        self.rank = rank
        self.alpha = alpha
        self.A = nn.Parameter(torch.empty(rank, d_in))
        self.B = nn.Parameter(torch.zeros(d_out, rank))
        nn.init.kaiming_uniform_(self.A, a=5 ** 0.5)

    def forward(self, x):
        return (x @ self.A.T @ self.B.T) * (
            self.alpha / self.rank
        )
```

`B=0` làm update ban đầu bằng 0.

<LessonNote>**Lỗi thường gặp:** khởi tạo cả A và B bằng 0. Khi đó gradient ban đầu có thể không tạo đường học hữu ích cho cả hai matrix.</LessonNote>

**Takeaway:** Shape đi `d_in → rank → d_out`.

## Bọc linear pretrained

```python
class LinearWithLoRA(nn.Module):
    def __init__(self, linear, rank=4, alpha=8.0):
        super().__init__()
        self.linear = linear
        self.lora = LoRAAdapter(
            linear.in_features,
            linear.out_features,
            rank,
            alpha,
        )
        for parameter in self.linear.parameters():
            parameter.requires_grad = False

    def forward(self, x):
        return self.linear(x) + self.lora(x)
```

<LessonNote>**Lỗi thường gặp:** tạo một `nn.Linear` mới rồi làm mất pretrained weights. Wrapper phải giữ đúng layer gốc.</LessonNote>

**Takeaway:** Base branch bất biến; adapter branch học task-specific update.

## Kiểm tra parameter trainable

```python
def count_trainable(module):
    return sum(
        p.numel() for p in module.parameters()
        if p.requires_grad
    )

base = nn.Linear(16, 12, bias=False)
layer = LinearWithLoRA(base, rank=2, alpha=4)

assert not layer.linear.weight.requires_grad
assert layer.lora.A.requires_grad
assert layer.lora.B.requires_grad
assert count_trainable(layer) == 2 * (16 + 12)
```

<LessonNote>**Production:** optimizer chỉ nên nhận parameter có `requires_grad=True`; log cả tổng và trainable count trước training.</LessonNote>

**Takeaway:** Công thức `r(d_in+d_out)` phải khớp `numel()` trong code.

## Smoke test độc lập

```python
import torch
from torch import nn

torch.manual_seed(3)
base = nn.Linear(4, 3, bias=False)
wrapped = LinearWithLoRA(base, rank=2, alpha=2)
x = torch.randn(5, 4)

with torch.no_grad():
    original = base(x)
    initial = wrapped(x)

assert initial.shape == (5, 3)
assert torch.allclose(initial, original)

loss = wrapped(x).square().mean()
loss.backward()
assert wrapped.linear.weight.grad is None
assert wrapped.lora.B.grad is not None

try:
    LoRAAdapter(4, 3, rank=0)
except ValueError:
    pass
else:
    raise AssertionError("rank=0 must fail")

try:
    LoRAAdapter(4, 3, rank=4)
except ValueError:
    pass
else:
    raise AssertionError("rank above min(d_in,d_out) must fail")

print(count_trainable(wrapped))  # 14
```

Sau một optimizer step, adapter output có thể khác 0 trong khi base weight vẫn giữ nguyên.

<LessonNote>**Takeaway:** Invariant gồm cùng output ban đầu, đúng shape, base không có gradient và rank lỗi bị từ chối trước khi chia `alpha/rank`.</LessonNote>
