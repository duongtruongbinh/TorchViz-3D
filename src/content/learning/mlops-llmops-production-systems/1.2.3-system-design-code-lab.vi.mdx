## Cấu trúc Thư mục Dự án Chuẩn MLOps

Hãy quan sát cấu trúc cây thư mục chuẩn được áp dụng trong toàn bộ khóa học:

```console
madewithml/
├── config.py             # Biến môi trường, đường dẫn lưu trữ, logger
├── data.py               # Thu thập, làm sạch, tiền xử lý dữ liệu
├── models.py             # Kiến trúc mạng nơ-ron (PyTorch / Transformers)
├── train.py              # Huấn luyện mô hình phân tán
├── tune.py               # Tinh chỉnh siêu tham số (Ray Tune)
├── evaluate.py           # Đánh giá toàn diện trên lát cắt dữ liệu
├── predict.py            # Dự đoán trên mẫu mới
├── serve.py              # Phục vụ REST API thời gian thực
└── utils.py              # Các hàm trợ giúp chung
tests/
├── code/                 # Unit tests cho mã nguồn
├── data/                 # Data validation tests
└── model/                # Model behavioral tests
```

## Tạo Virtual Environment & Quản lý Biến Môi trường

Thực thi các lệnh sau trên terminal để tạo môi trường Python biệt lập:

```bash
# Tạo môi trường ảo với Python 3.10
python3 -m venv venv

# Kích hoạt môi trường
source venv/bin/activate  # Trên Linux/macOS
# hoặc venv\Scripts\activate trên Windows

# Nâng cấp pip và cài đặt thư viện cần thiết
pip install --upgrade pip
pip install torch torchvision numpy pandas scikit-learn mlflow ray pytest
```

Tạo file `.env` để lưu trữ các tham số cục bộ:

```bash
touch .env
echo 'MODEL_REGISTRY="/tmp/mlflow"' >> .env
echo 'GITHUB_USERNAME="mlops-engineer"' >> .env
```

## Quản lý Cấu hình Tập trung với config.py

Tạo file `madewithml/config.py` để định nghĩa tất cả hằng số, đường dẫn và logger tập trung:

```python
from pathlib import Path
import logging
import sys

# Đường dẫn thư mục gốc dự án
BASE_DIR = Path(__file__).parent.parent.absolute()
DATA_DIR = Path(BASE_DIR, "datasets")
RESULTS_DIR = Path(BASE_DIR, "results")
LOGS_DIR = Path(BASE_DIR, "logs")

# Tạo các thư mục nếu chưa tồn tại
DATA_DIR.mkdir(parents=True, exist_ok=True)
RESULTS_DIR.mkdir(parents=True, exist_ok=True)
LOGS_DIR.mkdir(parents=True, exist_ok=True)

# Cấu hình Logger chuẩn hóa
logging_config = {
    "version": 1,
    "disable_existing_loggers": False,
    "formatters": {
        "minimal": {"format": "%(message)s"},
        "detailed": {
            "format": "%(levelname)s %(asctime)s [%(filename)s:%(funcName)s:%(lineno)d]\n%(message)s\n"
        },
    },
    "handlers": {
        "console": {
            "class": "logging.StreamHandler",
            "stream": sys.stdout,
            "formatter": "minimal",
            "level": logging.DEBUG,
        },
    },
    "root": {
        "handlers": ["console"],
        "level": logging.INFO,
    },
}

import logging.config
logging.config.dictConfig(logging_config)
logger = logging.getLogger("madewithml")
logger.info("✅ Cấu hình MLOps đã được khởi tạo thành công!")
```
