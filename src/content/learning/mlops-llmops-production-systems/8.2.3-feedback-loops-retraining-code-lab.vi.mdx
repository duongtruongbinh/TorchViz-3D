## Thu thập & Lọc Dữ liệu Phản hồi (Feedback Collection)

Tạo hàm ghi nhận phản hồi sửa lỗi từ người dùng:

```python
import pandas as pd
import json
from pathlib import Path
from datetime import datetime

def log_user_feedback(text: str, predicted_tag: str, user_corrected_tag: str, log_dir: str = "logs/feedback"):
    """Ghi nhận phản hồi sửa lỗi của người dùng vào log JSONL."""
    Path(log_dir).mkdir(parents=True, exist_ok=True)
    feedback_entry = {
        "timestamp": datetime.utcnow().isoformat(),
        "text": text,
        "predicted_tag": predicted_tag,
        "corrected_tag": user_corrected_tag,
    }
    
    log_fp = Path(log_dir) / "user_feedback.jsonl"
    with open(log_fp, "a") as f:
        f.write(json.dumps(feedback_entry) + "\n")
        
    print(f"📝 Đã lưu phản hồi cho mẫu: '{text[:30]}...' -> Nhãn sửa: {user_corrected_tag}")
```

## Thuật toán Active Learning Uncertainty Sampling

Chọn ra các mẫu có độ tự tin thấp nhất từ production traffic:

```python
import numpy as np

def active_learning_uncertainty_sampling(unlabeled_texts: list[str], predict_proba_fn, top_k: int = 100) -> list[dict]:
    """Lọc top_k mẫu có độ mơ hồ (uncertainty) cao nhất để gửi gán nhãn."""
    samples_with_uncertainty = []
    
    for text in unlabeled_texts:
        probs = predict_proba_fn(text) # Trả về mảng xác suất [0.45, 0.40, 0.10, 0.05]
        # Margin of confidence: chênh lệch giữa xác suất top 1 và top 2
        sorted_probs = np.sort(probs)[::-1]
        margin = sorted_probs[0] - sorted_probs[1]
        
        samples_with_uncertainty.append({
            "text": text,
            "margin": margin, # Margin càng nhỏ -> Độ phân vân càng cao
            "top_prediction": sorted_probs[0],
        })
        
    # Sắp xếp tăng dần theo margin (mơ hồ nhất lên đầu)
    samples_with_uncertainty.sort(key=lambda x: x["margin"])
    selected_samples = samples_with_uncertainty[:top_k]
    
    print(f"🎯 Đã chọn ra {len(selected_samples)} mẫu mơ hồ nhất cho Human Annotation.")
    return selected_samples
```
