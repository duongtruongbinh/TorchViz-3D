## Cơ chế Hoạt động của Git Pre-commit Hooks

**Pre-commit Hooks** là các kịch bản lệnh tự động chạy ngay khi bạn gõ lệnh `git commit` nhưng **trước khi** commit được tạo ra:

<ConceptFlow
  ariaLabel="Vòng lặp kiểm tra của Git Pre-commit Hook"
  items={[
    { title: '1. git commit -m "..."', detail: 'Kỹ sư thực hiện thao tác tạo commit mới.' },
    { title: '2. Run Pre-commit Hooks', detail: 'Tự động quét các file staging qua Ruff, Black, trailing-whitespace, check-yaml.' },
    { title: '3. Pass or Block', detail: 'Nếu PASS -> Commit thành công. Nếu FAIL -> Tự động sửa lỗi hoặc chặn lại yêu cầu kỹ sư sửa trước.' },
  ]}
/>

<LessonNote tone="tip">
  Pre-commit hooks hoạt động hoàn toàn ở môi trường local của kỹ sư, giúp phát hiện và dọn dẹp lỗi định dạng ngay tại chỗ trước khi đẩy lên CI/CD server.
</LessonNote>
