## Cấu trúc Thư mục Dự án Chuẩn MLOps

Hãy quan sát cấu trúc cây thư mục chuẩn được áp dụng trong toàn bộ khóa học:

```console
mlops_pipeline/
├── config.py             # Biến môi trường, đường dẫn lưu trữ, logger
├── data.py               # Thu thập, làm sạch, tiền xử lý dữ liệu
├── models.py             # Kiến trúc mạng nơ-ron (PyTorch / Transformers)
├── train.py              # Huấn luyện mô hình phân tán
├── tune.py               # Tinh chỉnh siêu tham số (Ray Tune)
├── evaluate.py           # Đánh giá toàn diện trên từng phân khúc dữ liệu
├── predict.py            # Dự đoán trên mẫu mới
├── serve.py              # Phục vụ REST API thời gian thực
└── utils.py              # Các hàm trợ giúp chung
tests/
├── code/                 # Unit tests cho mã nguồn
├── data/                 # Data validation tests
└── model/                # Model behavioral tests
```

### Câu lệnh khởi tạo nhanh khung dự án (Scaffold):

**Dành cho Linux / macOS / WSL / Git Bash:**
```bash
# 1. Tạo các thư mục dự án và tests
mkdir -p mlops_pipeline tests/code tests/data tests/model

# 2. Khởi tạo các file mã nguồn rỗng
touch mlops_pipeline/__init__.py \
  mlops_pipeline/config.py \
  mlops_pipeline/data.py \
  mlops_pipeline/models.py \
  mlops_pipeline/train.py \
  mlops_pipeline/tune.py \
  mlops_pipeline/evaluate.py \
  mlops_pipeline/predict.py \
  mlops_pipeline/serve.py \
  mlops_pipeline/utils.py \
  tests/__init__.py \
  tests/code/__init__.py \
  tests/data/__init__.py \
  tests/model/__init__.py
```

**Dành cho Windows (PowerShell):**
```powershell
# 1. Tạo các thư mục
New-Item -ItemType Directory -Force -Path `
  "mlops_pipeline", `
  "tests/code", `
  "tests/data", `
  "tests/model" | Out-Null

# 2. Khởi tạo các file rỗng trong mlops_pipeline/
$pipelineFiles = @(
  "__init__", "config", "data", "models",
  "train", "tune", "evaluate", "predict",
  "serve", "utils"
)
$pipelineFiles | ForEach-Object {
  New-Item -ItemType File -Force -Path "mlops_pipeline/$_.py" | Out-Null
}

# 3. Khởi tạo các file package rỗng trong tests/
$testFiles = @(
  "tests/__init__.py",
  "tests/code/__init__.py",
  "tests/data/__init__.py",
  "tests/model/__init__.py"
)
$testFiles | ForEach-Object {
  New-Item -ItemType File -Force -Path $_ | Out-Null
}
```

<LessonNote tone="tip">
  **Quy tắc vị trí làm việc (Working Directory):** Terminal của bạn luôn đứng ở thư mục gốc của dự án (nơi chứa đồng cấp cả `mlops_pipeline/`, `tests/` và `.venv`). Không `cd` vào trong thư mục con `mlops_pipeline/` để các lệnh `pytest tests/` và cú pháp import `from mlops_pipeline import ...` luôn hoạt động đồng bộ.
</LessonNote>

## Cài đặt `uv` & Cài đặt Thư viện Cốt lõi

Trong toàn bộ chuỗi bài thực hành MLOps, chúng ta sử dụng **`uv`** (trình quản lý dự án & package Python siêu tốc viết bằng Rust của Astral, nhanh hơn `pip` từ 10–100 lần) theo chuẩn quản trị dự án hiện đại (**PEP 621** & **`pyproject.toml`**):

### 1. Cài đặt `uv` vào máy tính:

```bash
# Trên macOS và Linux:
curl -LsSf https://astral.sh/uv/install.sh | sh

# Trên Windows (PowerShell):
powershell -c "irm https://astral.sh/uv/install.ps1 | iex"

# Hoặc cài nhanh qua pip nếu đã có sẵn Python:
pip install uv
```

### 2. Khởi tạo Dự án & Thêm Thư viện Cốt lõi:

Khởi tạo cấu hình dự án với `pyproject.toml` và cài đặt các thư viện ML/Serving cốt lõi:

```bash
# Khởi tạo dự án chuẩn với pyproject.toml
uv init --name mlops_pipeline

# Cài đặt các Core/Production Dependencies
uv add \
  torch torchvision \
  numpy pandas scikit-learn \
  mlflow ray \
  pydantic \
  fastapi uvicorn
```

### 3. Tạo file biến môi trường `.env`:

```bash
touch .env
echo 'MODEL_REGISTRY="/tmp/mlflow"' >> .env
echo 'GITHUB_USERNAME="mlops-engineer"' >> .env
```

### Cú pháp Quản lý Môi trường với `uv`

```bash
# 1. Đánh dấu và thêm các công cụ kiểm thử vào nhóm dev
uv add --dev pytest pytest-cov pre-commit

# 2. Khi ở bàn làm việc (DEV) hoặc máy kiểm định (CI): cài Core + Dev tools
uv sync

# 3. Khi đóng gói xuất xưởng lên Server phục vụ người dùng (PROD): chỉ cài Core
uv sync --no-dev
```

### Thực thi Lệnh An toàn với `uv run`

<LessonNote tone="tip">
  **Ưu điểm của `uv run`:** Không cần kích hoạt môi trường ảo thủ công (`source .venv/bin/activate`). `uv run` tự động đồng bộ và thực thi lệnh trực tiếp trong môi trường ảo chuẩn xác.
</LessonNote>

```bash
# Chạy toàn bộ bài test kiểm tra logic trên máy local
uv run pytest tests/code/
```

**Kết quả màn hình dự kiến (ở bước khởi tạo dự án):**
```text
platform linux -- Python 3.12.x, pytest-9.x.x
rootdir: /path/to/project
configfile: pyproject.toml
collected 0 items

no tests ran in 0.04s
```

<LessonNote tone="info">
  **Giải thích kết quả:** Thông báo `collected 0 items, no tests ran` xác nhận `uv` và `pytest` đã được cài đặt và liên kết cấu hình thành công! Do ở bước này chúng ta mới tạo cấu trúc thư mục rỗng, `pytest` chưa tìm thấy file `test_*.py` nào. Khi bạn viết các bài test kiểm tra logic ở các bài thực hành tiếp theo, `pytest` sẽ tự động thu thập và chạy ngay.

## Quản lý Cấu hình Tập trung với config.py

Mở file `mlops_pipeline/config.py` để định nghĩa tất cả hằng số, đường dẫn và logger tập trung:

```python
from pathlib import Path
import logging
import sys

# Đường dẫn thư mục gốc dự án
BASE_DIR = Path(__file__).parent.parent.absolute()
DATA_DIR = Path(BASE_DIR, "datasets")
RESULTS_DIR = Path(BASE_DIR, "results")
LOGS_DIR = Path(BASE_DIR, "logs")

# Tạo thư mục nếu chưa tồn tại
DATA_DIR.mkdir(parents=True, exist_ok=True)
RESULTS_DIR.mkdir(parents=True, exist_ok=True)
LOGS_DIR.mkdir(parents=True, exist_ok=True)

# Cấu hình logging
logging.basicConfig(
    level=logging.INFO,
    format="%(asctime)s [%(levelname)s] %(name)s: %(message)s",
    handlers=[
        logging.StreamHandler(sys.stdout),
        logging.FileHandler(LOGS_DIR / "app.log"),
    ],
)
logger = logging.getLogger("mlops_pipeline")
logger.info("Môi trường MLOps đã được khởi tạo thành công!")
```

<LessonNote tone="tip">
  **Thực hành tốt:** Không bao giờ hardcode đường dẫn tuyệt đối (như `/home/user/...`) trong code logic; luôn sử dụng biến dẫn xuất từ `BASE_DIR` hoặc biến môi trường `.env`.
</LessonNote>
