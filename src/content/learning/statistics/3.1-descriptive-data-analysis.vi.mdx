## Trung bình (Mean)

**Trung bình cộng (Sample Mean)** đại diện cho điểm cân bằng trọng tâm của dữ liệu. Nó được tính bằng cách cộng tất cả các giá trị lại rồi chia cho tổng số lượng phần tử.

<MdxFormula formula={"\\bar{x} = \\frac{1}{n} \\sum_{i=1}^{n} x_i = \\frac{x_1 + x_2 + \\cdots + x_n}{n}"} />

---

<MdxColumns>

<div>

**Bước 1 — Xác định cỡ mẫu <MdxFormula inline formula={"n"} />:**
- Số lượng phần tử <MdxFormula inline formula={"n = 10"} />

**Bước 2 — Tính tổng tất cả giá trị:**
<MdxFormula formula={"\\begin{aligned} \\sum x_i &= 12 + 15 + 12 + 18 + 20 \\\\ &\\quad + 12 + 22 + 15 + 30 + 24 = 180 \\text{ ms} \\end{aligned}"} />

**Bước 3 — Tính trung bình cộng:**
<MdxFormula formula={"\\bar{x} = \\frac{180}{10} = 18.0 \\text{ ms}"} />

**Kết luận:** Độ trễ phản hồi trung bình là **18.0 ms**.

</div>

<div>

```python
import numpy as np
import pandas as pd

data = [12, 15, 12, 18, 20, 12, 22, 15, 30, 24]

# Cách 1: Python thuần
mean_py = sum(data) / len(data)

# Cách 2: NumPy
mean_np = np.mean(data)

# Cách 3: Pandas Series
mean_pd = pd.Series(data).mean()

print(f"Python thuần : {mean_py} ms")
print(f"NumPy        : {mean_np} ms")
print(f"Pandas       : {mean_pd} ms")
```
```output
Python thuần : 18.0 ms
NumPy        : 18.0 ms
Pandas       : 18.0 ms
```

</div>

</MdxColumns>

## Trung vị (Median)

Trung vị là giá trị **ở chính giữa** khi sắp xếp dữ liệu theo thứ tự tăng dần. Đây là thước đo **bền vững** (robust) — không bị ảnh hưởng bởi outliers.

<MdxFormula formula={"\\text{Median} = \\begin{cases} x_{\\left(\\frac{n+1}{2}\\right)} & \\text{nếu } n \\text{ lẻ} \\\\ \\dfrac{x_{\\left(\\frac{n}{2}\\right)} + x_{\\left(\\frac{n}{2}+1\\right)}}{2} & \\text{nếu } n \\text{ chẵn} \\end{cases}"} />

---

<MdxColumns>

<div>

**Bước 1 — Sắp xếp tăng dần:**

<MdxFormula formula={"\\begin{aligned} X_{\\text{sorted}} = \\{&12, 12, 12, 15, \\underbrace{15}_{(5)}, \\\\ &\\underbrace{18}_{(6)}, 20, 22, 24, 30\\} \\end{aligned}"} />

**Bước 2 — Xác định vị trí giữa:**

Vì <MdxFormula inline formula={"n = 10"} /> là **số chẵn**, trung vị là trung bình cộng của phần tử thứ **5** và **6**:

<MdxFormula formula={"x_{(5)} = 15, \\quad x_{(6)} = 18"} />

**Bước 3 — Tính trung vị:**

<MdxFormula formula={"\\text{Median} = \\frac{x_{(5)} + x_{(6)}}{2} = \\frac{15 + 18}{2} = 16.5 \\text{ ms}"} />

**Kết luận:** Trung vị là **16.5 ms**.

</div>

<div>

```python
import numpy as np
import pandas as pd

data = [12, 15, 12, 18, 20, 12, 22, 15, 30, 24]

# Sắp xếp & Tính trung vị
sorted_data = sorted(data)
median_py = (sorted_data[4] + sorted_data[5]) / 2
median_np = np.median(data)
median_pd = pd.Series(data).median()

print(f"Đã sắp xếp : {sorted_data}")
print(f"Thủ công   : {median_py} ms")
print(f"NumPy      : {median_np} ms")
print(f"Pandas     : {median_pd} ms")
```
```output
Đã sắp xếp : [12, 12, 12, 15, 15, 18, 20, 22, 24, 30]
Thủ công   : 16.5 ms
NumPy      : 16.5 ms
Pandas     : 16.5 ms
```

</div>

</MdxColumns>

---

<LessonNote label="Median kháng Outliers">

Dùng lại ví dụ outlier: yêu cầu thứ 10 là **300 ms** thay vì 30 ms.

Dữ liệu sắp xếp: `[12, 12, 12, 15, 15, 18, 20, 22, 24, 300]`

Median vẫn là <MdxFormula inline formula={"(15 + 18)/2 = 16.5 \\text{ ms}"} /> — **không thay đổi**!

Đây chính là lý do Median được dùng để thống kê **thu nhập** và **giá nhà** — những lĩnh vực có nhiều outliers lớn.

</LessonNote>

## Yếu vị (Mode)

Yếu vị là giá trị xuất hiện **nhiều lần nhất** trong tập dữ liệu. Mode là thước đo duy nhất dùng được cho cả **dữ liệu định tính** (ví dụ: màu sắc, nhãn hiệu).

<MdxFormula formula={"\\text{Mode} = \\underset{x}{\\arg\\max}\\ f(x)"} />

trong đó <MdxFormula inline formula={"f(x)"} /> là tần suất (frequency) của giá trị <MdxFormula inline formula={"x"} />.

---

<MdxColumns>

<div>

**Bước 1 — Đếm tần suất từng giá trị:**

<MdxTable
  caption="Tần suất xuất hiện"
  headers={["Giá trị", "Tần suất"]}
  rows={[
    ["12 ms", "3 lần (cao nhất)"],
    ["15 ms", "2 lần"],
    ["18 ms", "1 lần"],
    ["20 ms", "1 lần"],
    ["22 ms", "1 lần"],
    ["24 ms", "1 lần"],
    ["30 ms", "1 lần"]
  ]}
/>

**Bước 2 — Xác định giá trị cao nhất:**

Giá trị `12` xuất hiện **3 lần** — nhiều nhất trong tập.

**Kết luận:**

<MdxFormula formula={"\\text{Mode} = 12 \\text{ ms}"} />

</div>

<div>

```python
import pandas as pd
from collections import Counter
from scipy import stats

data = [12, 15, 12, 18, 20, 12, 22, 15, 30, 24]

# Cách 1: Counter
mode_py = Counter(data).most_common(1)[0][0]

# Cách 2: Pandas
mode_pd = list(pd.Series(data).mode())

# Cách 3: scipy
mode_scipy = stats.mode(data, keepdims=True)

print(f"Counter : {mode_py} ms")
print(f"Pandas  : {mode_pd} ms")
print(f"scipy   : {mode_scipy.mode[0]} ms (lặp {mode_scipy.count[0]} lần)")
```
```output
Counter : 12 ms
Pandas  : [12] ms
scipy   : 12 ms (lặp 3 lần)
```

## Histogram & Nhận xét Mean, Median và Mode

Histogram dưới đây biểu diễn tần số của từng mức độ trễ với **bin rộng 1 ms**. Ba đường dọc đánh dấu vị trí của **Mode**, **Median** và **Mean** trên cùng một trục.

<ProbabilityChapterVisual kind="descriptive-center-histogram" />

---

<MdxColumns>

<div>

### Vẽ bằng Python

```python
import numpy as np
import matplotlib.pyplot as plt
from scipy import stats

data = [12, 15, 12, 18, 20, 12, 22, 15, 30, 24]

mean = np.mean(data)
median = np.median(data)
mode = stats.mode(data, keepdims=True).mode[0]

bins = np.arange(min(data) - 0.5, max(data) + 1.5, 1)
plt.hist(data, bins=bins, edgecolor="white")
plt.axvline(mode, label=f"Mode = {mode} ms")
plt.axvline(median, label=f"Median = {median} ms")
plt.axvline(mean, label=f"Mean = {mean} ms")
plt.xlabel("Độ trễ phản hồi (ms)")
plt.ylabel("Tần số")
plt.legend()
plt.show()
```

</div>

<div>

### Đọc biểu đồ

- **Mode = 12 ms:** cột tại 12 ms cao nhất, với 3 lần xuất hiện.
- **Median = 16.5 ms:** nằm giữa 15 ms và 18 ms, chia 10 quan sát thành hai nửa.
- **Mean = 18 ms:** nằm bên phải Median vì giá trị 30 ms kéo điểm cân bằng về phía các giá trị lớn.
- Thứ tự <MdxFormula inline formula={"\\text{Mode} < \\text{Median} < \\text{Mean}"} /> cho thấy mẫu có **đuôi phải dài hơn**. Tuy nhiên, với chỉ 10 quan sát, ta nên xem đây là nhận xét về bộ dữ liệu hiện tại thay vì kết luận chắc chắn về toàn bộ phân phối.
