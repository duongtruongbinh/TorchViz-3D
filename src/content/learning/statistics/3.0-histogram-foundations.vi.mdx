## Code Python: tạo histogram đầu tiên

Sau khi đã hiểu bin và phép đếm, `matplotlib` chỉ còn là cách tự động hóa những bước đó.

```python
import numpy as np
import matplotlib.pyplot as plt

data = np.array([
    18, 22, 25, 25, 27, 29, 30, 31, 31, 32,
    33, 34, 34, 35, 35, 36, 37, 38, 38, 39,
    40, 41, 42, 44, 45, 47, 50, 52, 55, 60
])

n = len(data)
num_bins = round(np.sqrt(n))

print(f"Số quan sát: {n}")
print(f"Số bin gợi ý: {num_bins}")

plt.hist(data, bins=num_bins, edgecolor="black")
plt.xlabel("Thời gian hoàn thành (phút)")
plt.ylabel("Số sinh viên")
plt.title(f"Histogram với {num_bins} bin")
plt.show()
```

- `bins` điều khiển cách chia miền giá trị.
- `plt.hist()` tự gán quan sát vào bin và đếm chúng.
- `edgecolor` làm ranh giới giữa các bin dễ nhìn hơn.

## Code Python: nhìn thấy dữ liệu được chia bin như thế nào

`np.histogram()` trả về cả số quan sát và ranh giới của từng bin, giúp ta kiểm tra điều mà biểu đồ đã tóm tắt.

```python
import numpy as np

data = np.array([
    18, 22, 25, 25, 27, 29, 30, 31, 31, 32,
    33, 34, 34, 35, 35, 36, 37, 38, 38, 39,
    40, 41, 42, 44, 45, 47, 50, 52, 55, 60
])

num_bins = round(np.sqrt(len(data)))
counts, bin_edges = np.histogram(data, bins=num_bins)

for index, count in enumerate(counts):
    left = bin_edges[index]
    right = bin_edges[index + 1]
    closing = "]" if index == len(counts) - 1 else ")"
    print(
        f"Bin {index + 1}: [{left:.1f}, {right:.1f}{closing} "
        f"chứa {count} quan sát"
    )
```

Bin cuối bao gồm đầu mút bên phải để giá trị lớn nhất không bị bỏ ra ngoài.

## Code Python: quá ít, hợp lý và quá nhiều bin

Để so sánh công bằng, hãy giữ chung dữ liệu và hai trục, chỉ thay đổi số bin.

```python
import numpy as np
import matplotlib.pyplot as plt

rng = np.random.default_rng(42)
data = np.concatenate([
    rng.normal(loc=30, scale=4, size=120),
    rng.normal(loc=45, scale=3, size=80)
])

bin_choices = {
    "Quá ít bin": 2,
    "Theo căn bậc hai": round(np.sqrt(len(data))),
    "Quá nhiều bin": 40,
}

fig, axes = plt.subplots(1, 3, figsize=(15, 4), sharex=True, sharey=True)

for axis, (title, num_bins) in zip(axes, bin_choices.items()):
    axis.hist(data, bins=num_bins, edgecolor="black")
    axis.set_title(f"{title}\n{num_bins} bin")
    axis.set_xlabel("Giá trị")

axes[0].set_ylabel("Tần số")
plt.tight_layout()
plt.show()
```

Hãy hỏi: với 2 bin, hai cụm còn nhìn thấy không? Với 40 bin, những cột nhỏ có tạo ra quá nhiều đỉnh giả không?

## Code Python: so sánh các quy tắc chọn bin

NumPy hỗ trợ nhiều phương pháp chọn ranh giới bin. Tên phương pháp được truyền trực tiếp vào `np.histogram_bin_edges()`.

```python
import numpy as np
import matplotlib.pyplot as plt

rng = np.random.default_rng(42)
data = rng.lognormal(mean=3.2, sigma=0.35, size=300)
methods = ["sqrt", "sturges", "fd", "auto"]

fig, axes = plt.subplots(2, 2, figsize=(12, 8), sharex=True)

for axis, method in zip(axes.flat, methods):
    bin_edges = np.histogram_bin_edges(data, bins=method)
    num_bins = len(bin_edges) - 1
    axis.hist(data, bins=bin_edges, edgecolor="black")
    axis.set_title(f"bins='{method}' → {num_bins} bin")
    axis.set_xlabel("Giá trị")
    axis.set_ylabel("Tần số")

plt.tight_layout()
plt.show()
```

`"sqrt"` và `"sturges"` là hai quy tắc khởi đầu; `"fd"` dùng Freedman–Diaconis; `"auto"` để NumPy chọn từ các quy tắc có sẵn.
