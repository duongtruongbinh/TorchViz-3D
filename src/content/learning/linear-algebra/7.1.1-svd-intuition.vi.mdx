## Một Factorization cho mọi Matrix

Eigen decomposition rất mạnh nhưng cần square matrix và diagonalization còn yêu cầu đủ independent eigenvectors.

SVD áp dụng cho mọi real matrix:

<BlockMath formula="A\in\mathbb{R}^{m\times n}" />

dù matrix vuông, cao, rộng, full rank hay rank deficient.

Đây là lý do SVD xuất hiện rộng rãi trong numerical linear algebra và machine learning.

</MdxPage>

## A bằng U Sigma V transpose

Với reduced SVD:

- Các cột của <InlineMath formula="U" /> orthonormal

## Trực giác Rotate Scale Rotate

Trong hình học 2D, có thể đọc SVD theo ba bước.

<InlineMath formula="V^\top" /> đổi sang các right singular directions.

<InlineMath formula="\Sigma" /> scale từng direction theo singular values.

<InlineMath formula="U" /> đưa các directions sang output space.

## Singular Vectors

Right singular vectors thỏa:

<BlockMath formula="A\mathbf{v}_i=\sigma_i\mathbf{u}_i" />

Matrix đưa input direction <InlineMath formula="\mathbf{v}_i" /> sang output direction <InlineMath formula="\mathbf{u}_i" /> và scale độ dài theo <InlineMath formula="\sigma_i" />.

Vì <InlineMath formula="\mathbf{v}_i" /> và <InlineMath formula="\mathbf{u}_i" /> thuộc hai spaces khác nhau, SVD xử lý tự nhiên cả rectangular matrices.

</MdxPage>

## Liên hệ với AtA

Từ SVD:

<BlockMath formula="A^\top A=V\Sigma^\top\Sigma V^\top" />

Do đó right singular vectors là eigenvectors của <InlineMath formula="A^\top A" />.

Các singular values thỏa:

<BlockMath formula="\sigma_i^2=\lambda_i(A^\top A)" />

Đây là cầu nối giữa eigen decomposition và SVD.

</MdxPage>

<MdxPage page={5}>

## Rank qua Singular Values

Trong exact arithmetic:

<BlockMath formula="\operatorname{rank}(A)=\#\{i:\sigma_i>0\}" />

Rank bằng số singular values khác 0.

Trong floating point computation, giá trị rất nhỏ không được phân loại bằng so sánh exact zero.

Numerical rank dùng một threshold phụ thuộc scale và precision.

Đây là lý do `np.linalg.matrix_rank` dùng singular values.

</MdxPage>

## SVD trong NumPy

```python
import numpy as np

A = np.array([
    [3.0, 1.0],
    [1.0, 3.0],
    [0.0, 2.0],
])

U, s, Vt = np.linalg.svd(A, full_matrices=False)

print(U.shape)
print(s.shape)
print(Vt.shape)

A_reconstructed = (U * s) @ Vt

print(np.allclose(A_reconstructed, A))
```

NumPy trả singular values dưới dạng vector một chiều `s`, không tạo matrix <InlineMath formula="\Sigma" /> đầy đủ trừ khi ta tự dựng.

Bài cuối dùng singular values để tạo low rank approximation và giảm chiều.

</MdxPage>
