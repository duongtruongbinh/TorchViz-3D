## Đặt đúng giả định memory trước khi so phương pháp

Các phương pháp CL hoạt động dưới những giả định memory khác nhau. So sánh chúng mà không công bố quyền truy cập lịch sử sẽ dẫn đến kết luận không công bằng.

<ConceptSpectrum
  ariaLabel="Phổ ràng buộc bộ nhớ trong Continual Learning"

    { label: 'Relaxed', detail: 'Giữ một buffer giới hạn' },

    { label: 'Unlimited', detail: 'Giữ toàn bộ lịch sử; joint training khả dụng' },

/>

Strict memory ưu tiên regularization, parameter isolation hoặc pseudo-data; relaxed memory mở replay trực tiếp; unlimited memory cần full-history baseline. External memory là một lớp riêng vì quyền đọc, ghi và xóa có thể được kiểm soát mà không cập nhật toàn bộ tham số.

Nguồn: [Shi et al., §6.3](https://arxiv.org/html/2404.16789v3#S6.SS3).
