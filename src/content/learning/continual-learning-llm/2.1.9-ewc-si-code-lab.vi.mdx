## Câu hỏi nghiên cứu

Lab trước đã tạo một experiment contract dùng chung cho SeqFT và Experience Replay. Lần này ta giữ nguyên task stream, sample ID, training budget và evaluator, rồi chỉ thay cơ chế bảo vệ model bằng Elastic Weight Consolidation (EWC) và Synaptic Intelligence (SI).

Mục tiêu không phải ép EWC hoặc SI đạt điểm cao nhất. Ta muốn biết importance mà mỗi phương pháp tính ra có thực sự dự báo tham số nào cần được bảo vệ hay không, và mức bảo vệ đó đánh đổi với khả năng học task mới như thế nào.

Code không được viết từ công thức rồi tự nhận là đã chạy trên language model. Nhánh EWC port trực tiếp ba thao tác từ repository [`Neurotechnology/LLM_EWC`](https://github.com/Neurotechnology/LLM_EWC): chạy một pass để lấy squared gradient, lưu checkpoint làm anchor, rồi cộng Fisher-weighted quadratic loss. Repository này đi cùng thí nghiệm full-parameter continual pretraining trên Gemma2-2B <Cite paper="sliogeris2025gemmaEwc" evidence="ewc-si-lab-methods-01-sliogeris2025gemmaEwc" />. Model của source được thay bằng Pythia-160M và MMLU/CulturaX được thay bằng task stream của course.

Với SI, hiện chưa có public repository causal-LLM đủ điều kiện để dùng làm nguồn end-to-end. Lab lấy update rule từ code chính thức của tác giả, rồi đối chiếu khả năng chuyển sang Transformer với thí nghiệm Whisper-small áp dụng cả EWC lẫn SI <Cite paper="ahadzi2025childrenAsr" evidence="ewc-si-lab-methods-02-ahadzi2025childrenAsr" />. Đây là khác biệt provenance quan trọng: EWC có LLM paper + code; SI có code thuật toán gốc + paper Transformer thực nghiệm, nhưng paper Whisper không phát hành training code.

## Strategy hooks

Ta giữ vòng lặp PyTorch của baseline và thêm bốn hook. Khi strategy không làm gì, đường chạy phải tương đương SeqFT. Đây là sanity check đầu tiên trước khi viết EWC hoặc SI.

```python
class ContinualStrategy:
    """Interface nhỏ nhất để gắn retention strategy vào train loop hiện có."""

    name = "seqft"

    def start_task(self, model, task_id): pass
    def penalty(self, model): return next(model.parameters()).new_zeros(())
    def capture_task_gradient(self, model, regularizer_multiplier): pass
    def before_optimizer_step(self, model, update_will_apply): pass
    def after_optimizer_step(self, model, update_applied): pass
    def consolidate_task(self, model, task_id, task_rows):
        return {"seconds": 0.0, "examples": 0}
    def importance_tensors(self): return {}
    def anchor_tensors(self): return {}
    def penalty_factor(self): return 0.0
    def state_bytes(self, include_transient=False): return 0


class NoOpStrategy(ContinualStrategy):
    """Control dùng để xác nhận train loop có hooks vẫn tái tạo SeqFT."""
    pass
```

Điểm chèn hook quanh optimizer step:

```python
task_loss = answer_token_nll(model, batch)
retention_loss = strategy.penalty(model)
loss = (task_loss + retention_loss) / grad_accum_steps
scaler.scale(loss).backward()

if is_update or is_last:
    scaler.unscale_(optimizer)
    partial_rescale = grad_accum_steps / accumulated_microbatches
    for parameter in model.parameters():
        if parameter.grad is not None:
            parameter.grad.mul_(partial_rescale)
    strategy.capture_task_gradient(
        model,
        regularizer_multiplier=1.0,
    )
    grad_norm = torch.nn.utils.clip_grad_norm_(model.parameters(), 1.0)
    gradients_are_finite = torch.isfinite(grad_norm).item()
    strategy.before_optimizer_step(model, update_will_apply=gradients_are_finite)
    scale_before = scaler.get_scale()
    scaler.step(optimizer)
    scaler.update()
    amp_skipped = scaler.is_enabled() and scaler.get_scale() < scale_before
    strategy.after_optimizer_step(
        model,
        update_applied=gradients_are_finite and not amp_skipped,
    )
    optimizer.zero_grad(set_to_none=True)
```

`capture_task_gradient` chạy sau khi gradient đã được unscale và final partial group đã được renormalize, nhưng trước gradient clipping. Vì vậy update cuối vẫn mang mean-gradient semantics giống một accumulation group đầy đủ. Đây là raw gradient của task loss, tương ứng với `unreg_grads` trong reference implementation. `before_optimizer_step` và `after_optimizer_step` đo <InlineMath formula="\Delta\theta_i" /> thật sau AdamW, clipping, weight decay và mixed precision. Không chuyển task gradient xuống sau clipping: SI ghép gradient toán học của task với quãng đường parameter thực sự đã đi.

Không reset `GradScaler` khi chuyển task. Reset về scale mặc định ở mỗi boundary có thể lặp lại các overflow update đầu task và khiến số update thật khác nhau giữa method. Notebook dùng initial scale thấp từ đầu và coi `applied_updates == attempted_updates` là một invariant bắt buộc. Một run có skipped hoặc non-finite update dừng hẳn; code không hạ precision, đổi model hay âm thầm tiếp tục bằng trajectory khác.

## EWC tại task boundary

EWC làm chậm thay đổi ở những parameter quan trọng với task cũ <Cite paper="kirkpatrick2017overcoming" evidence="ewc-si-lab-methods-03-kirkpatrick2017overcoming" />. Trong lab này, sau khi học xong một task, EWC chạy một consolidation pass trên dữ liệu của task vừa hoàn thành. Ta bình phương gradient của observed-label answer-token mean NLL để tạo một diagonal empirical gradient-Fisher proxy. Đây không phải exact Fisher phải cộng qua mọi output có thể có. Sau consolidation, dữ liệu task được giải phóng và chỉ anchor cùng importance được giữ lại.

<BlockMath formula="F_i \approx \frac{1}{N}\sum_{n=1}^{N}\left(\frac{\partial \ell_n}{\partial\theta_i}\right)^2" />

<BlockMath formula="L_{EWC}=L_{new}+\frac{\lambda}{2}\sum_i F_i(\theta_i-\theta_i^*)^2" />

Implementation dưới đây giữ đúng ba bước của source Gemma2 nhưng tổng quát hóa cho nhiều task. Sau mỗi boundary, các quadratic cũ được gộp thành một precision và một center tương đương; nhờ vậy state không tăng tuyến tính theo số task.

```python
def tensor_bytes(tensors):
    return sum(t.numel() * t.element_size() for t in tensors)


class QuadraticStrategy(ContinualStrategy):
    def __init__(self, strength):
        self.strength = strength
        self.center = {}
        self.precision = {}

    def penalty(self, model):
        if not self.precision:
            return super().penalty(model)
        total = next(model.parameters()).new_zeros((), dtype=torch.float32)
        for name, parameter in named_trainable_parameters(model):
            if name in self.precision:
                distance = parameter.float() - self.center[name]
                total += (self.precision[name] * distance.square()).sum()
        return 0.5 * self.strength * total

    @torch.no_grad()
    def merge_quadratic(self, model, new_precision):
        for name, parameter in named_trainable_parameters(model):
            importance = new_precision[name].float()
            current = parameter.detach().float()
            if name not in self.precision:
                self.precision[name] = importance.clone()
                self.center[name] = current.clone()
                continue

            old_precision = self.precision[name]
            total_precision = old_precision + importance
            numerator = old_precision * self.center[name] + importance * current
            self.center[name] = torch.where(
                total_precision > 0,
                numerator / total_precision.clamp_min(1e-30),
                current,
            )
            self.precision[name] = total_precision

    def importance_tensors(self): return self.precision
    def anchor_tensors(self): return self.center
    def penalty_factor(self): return 0.5 * self.strength
    def state_bytes(self, include_transient=False):
        return tensor_bytes(self.center.values()) + tensor_bytes(self.precision.values())


class EWCStrategy(QuadraticStrategy):
    name = "ewc"

    def __init__(self, strength, fisher_samples):
        super().__init__(strength)
        self.fisher_samples = fisher_samples

    def estimate_fisher(self, model, task_rows):
        rows = list(task_rows[:min(self.fisher_samples, len(task_rows))])
        fisher = {
            name: torch.zeros_like(parameter, dtype=torch.float32)
            for name, parameter in named_trainable_parameters(model)
        }
        was_training = model.training
        model.eval()

        for row in tqdm(rows, desc="  Empirical Fisher", leave=False):
            model.zero_grad(set_to_none=True)
            batch = {
                key: value.to(DEVICE)
                for key, value in collate_batch([encode_train_row(row)]).items()
            }
            answer_token_nll(model, batch).backward()
            for name, parameter in named_trainable_parameters(model):
                if parameter.grad is not None:
                    fisher[name].add_(parameter.grad.detach().float().square())

        model.zero_grad(set_to_none=True)
        for value in fisher.values():
            value.div_(max(len(rows), 1))
        model.train(was_training)
        return fisher, len(rows)

    def consolidate_task(self, model, task_id, task_rows):
        started = time.perf_counter()
        fisher, examples = self.estimate_fisher(model, task_rows)
        assert all(
            torch.isfinite(value).all() and (value >= 0).all()
            for value in fisher.values()
        )
        self.merge_quadratic(model, fisher)
        return {
            "seconds": time.perf_counter() - started,
            "examples": examples,
        }
```

Ba invariant phải pass trước khi chạy benchmark: mọi <InlineMath formula="F_i\ge 0" />, penalty bằng 0 ngay tại anchor và consolidation không làm thay đổi model parameter.

## SI trên optimization trajectory

SI tích lũy thông tin liên quan đến task tại từng parameter trong quá trình học <Cite paper="zenke2017continual" evidence="ewc-si-lab-methods-04-zenke2017continual" />. Nó không đợi đến checkpoint cuối để hỏi parameter nhạy đến đâu. Trong lúc optimizer di chuyển, SI cộng credit <InlineMath formula="-g_i^{task}\Delta\theta_i" /> từ từng update thật. Gradient ở đây chỉ đến từ loss của task hiện tại; nếu trộn gradient của SI penalty vào credit, importance mới sẽ tự củng cố importance cũ và không còn đo đóng góp của task đang học.

<BlockMath formula="\omega_i\leftarrow\omega_i-g_i^{task}\Delta\theta_i" />

<BlockMath formula="\Omega_i\leftarrow\max\left(0,\Omega_i+\frac{\omega_i}{(\theta_i^{end}-\theta_i^{start})^2+\xi}\right)" />

```python
class SIStrategy(ContinualStrategy):
    name = "si"

    def __init__(self, strength, damping):
        self.strength, self.damping = strength, damping
        self.anchor, self.importance = {}, {}
        self.task_start, self.path_credit = {}, {}
        self.before_step, self.task_gradient = {}, {}

    @torch.no_grad()
    def start_task(self, model, task_id):
        self.task_start = {
            name: parameter.detach().float().clone()
            for name, parameter in named_trainable_parameters(model)
        }
        self.path_credit = {
            name: torch.zeros_like(parameter, dtype=torch.float32)
            for name, parameter in named_trainable_parameters(model)
        }

    def penalty(self, model):
        if not self.importance:
            return super().penalty(model)
        total = next(model.parameters()).new_zeros((), dtype=torch.float32)
        for name, parameter in named_trainable_parameters(model):
            if name in self.importance:
                distance = parameter.float() - self.anchor[name]
                total += (self.importance[name] * distance.square()).sum()
        return self.strength * total

    @torch.no_grad()
    def capture_task_gradient(self, model, regularizer_multiplier=1.0):
        self.task_gradient.clear()
        for name, parameter in named_trainable_parameters(model):
            if parameter.grad is None:
                continue
            task_gradient = parameter.grad.detach().float().clone()
            if name in self.importance:
                regularizer_gradient = (
                    2.0 * self.strength * self.importance[name]
                    * (parameter.detach().float() - self.anchor[name])
                )
                task_gradient.sub_(regularizer_multiplier * regularizer_gradient)
            self.task_gradient[name] = task_gradient

    @torch.no_grad()
    def before_optimizer_step(self, model, update_will_apply):
        self.before_step.clear()
        if not update_will_apply:
            self.task_gradient.clear()
            return
        self.before_step = {
            name: parameter.detach().float().clone()
            for name, parameter in named_trainable_parameters(model)
            if name in self.task_gradient
        }

    @torch.no_grad()
    def after_optimizer_step(self, model, update_applied=True):
        if update_applied:
            for name, parameter in named_trainable_parameters(model):
                if name in self.before_step:
                    delta = parameter.detach().float() - self.before_step[name]
                    self.path_credit[name].add_(-self.task_gradient[name] * delta)
        self.before_step.clear()
        self.task_gradient.clear()

    @torch.no_grad()
    def consolidate_task(self, model, task_id, task_rows=None):
        for name, parameter in named_trainable_parameters(model):
            current = parameter.detach().float()
            displacement_sq = (current - self.task_start[name]).square()
            contribution = self.path_credit[name] / (displacement_sq + self.damping)
            previous = self.importance.get(name, torch.zeros_like(contribution))
            self.importance[name] = torch.relu(previous + contribution)
            self.anchor[name] = current.clone()

        self.task_start.clear()
        self.path_credit.clear()
        self.before_step.clear()
        self.task_gradient.clear()
        return {"seconds": 0.0, "examples": 0}

    def importance_tensors(self): return self.importance
    def anchor_tensors(self): return self.anchor
    def penalty_factor(self): return self.strength

    def state_bytes(self, include_transient=False):
        tensors = list(self.anchor.values()) + list(self.importance.values())
        if include_transient:
            tensors += list(self.task_start.values())
            tensors += list(self.path_credit.values())
            tensors += list(self.before_step.values())
            tensors += list(self.task_gradient.values())
        return tensor_bytes(tensors)
```

Tại task boundary, phép `ReLU` được áp dụng sau khi cộng contribution mới vào cumulative importance, giống reference implementation của tác giả. def eligible(candidate, seqft):
    """Không mua retention bằng cách làm từng task khó học hơn SeqFT quá 3 điểm %."""
    diagonal_ok = np.all(candidate.diagonal >= seqft.diagonal - 0.03)
    gain_ok = candidate.mean_learning_gain >= seqft.mean_learning_gain - 0.03
    return diagonal_ok and gain_ok

## Nhìn vào importance

Điểm benchmark cho biết method có hoạt động trong fixture này hay không. XAI section phải lưu dữ liệu ngay trong training loop rồi mới dùng các probe sau để kiểm tra lời giải thích về cơ chế:

1. **Loss trajectory:** task loss, retention penalty và total loss đổi thế nào qua từng optimizer update?
2. **Layerwise importance:** mean, upper quantile, parameter-weighted non-zero ratio và tổng importance nằm nhiều ở embedding, attention, MLP hay final norm?
3. **Importance–drift:** parameter có importance cao có dịch chuyển ít hơn khi học task kế tiếp không?
4. **Penalty attribution:** module nào đóng góp nhiều nhất vào <InlineMath formula="\Omega_i(\theta_i-\theta_i^*)^2" /> trong lúc train?
5. **Agreement:** Spearman correlation và top-k overlap giữa Fisher importance với SI importance cao đến đâu?
6. **Perturbation:** tại post-Task-A và final-stream, qua nhiều noise seed có cùng norm, Task-A loss thay đổi ra sao ở nhóm within-tensor importance cao, random và thấp?
