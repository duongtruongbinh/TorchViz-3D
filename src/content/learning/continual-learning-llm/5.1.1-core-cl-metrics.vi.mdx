## OP: Hiệu năng tổng thể hiện tại

**Overall Performance (OP)** trả lời câu hỏi: sau stage hiện tại, model làm tốt trung bình đến đâu trên tất cả task đã học?

<BlockMath formula="\operatorname{OP}_t=\frac{1}{t}\sum_{j=1}^{t}P_{t,j}" />

Giả sử sau khi học xong Task C, model đạt các kết quả sau:

<MetricBars
  ariaLabel="Hiệu năng trên ba task sau stage C"
  max={100}
  items={[
    { label: 'Task A', value: 60, valueLabel: '60%', detail: 'Task cũ nhất', tone: 'danger' },
    { label: 'Task B', value: 75, valueLabel: '75%', detail: 'Task cũ gần nhất', tone: 'primary' },
    { label: 'Task C', value: 90, valueLabel: '90%', detail: 'Task vừa học', tone: 'success' },
  ]}
/>

<BlockMath formula="\operatorname{OP}_3=\frac{60+75+90}{3}=75\%" />

OP càng cao thì hiệu năng tổng thể càng tốt. Tuy nhiên, giá trị trung bình <InlineMath formula="75\%" /> không cho biết Task A đã từng tốt đến đâu trước khi giảm xuống <InlineMath formula="60\%" />. Muốn nhìn thấy phần bị quên, ta cần metric F ở trang tiếp theo.

<BlockMath formula="F_3^{\mathrm{peak}}=\frac{(90-60)+(85-75)}{2}=20\text{ điểm}" />

Viết tổng quát cho <InlineMath formula="t-1" /> task cũ:

<BlockMath formula="F_t^{\mathrm{peak}}=\frac{1}{t-1}\sum_{j=1}^{t-1}\left[\max_{\ell\in\{1,\ldots,t-1\}}P_{\ell,j}-P_{t,j}\right]" />

Đây cũng là baseline được dùng trong định nghĩa forgetting phổ biến của Chaudhry et al.: so checkpoint hiện tại với **đỉnh hiệu năng trước đó** của từng task <Cite paper="chaudhry2019tiny" evidence="core-cl-metrics-02-chaudhry2019tiny" />.

- <InlineMath formula="F^{\mathrm{peak}}>0" />: checkpoint hiện tại thấp hơn đỉnh lịch sử; model đã mất một phần hiệu năng từng có.
- <InlineMath formula="F^{\mathrm{peak}}=0" />: checkpoint hiện tại vẫn ở đúng đỉnh cũ.
- <InlineMath formula="F^{\mathrm{peak}}<0" />: checkpoint hiện tại còn vượt mọi kết quả trước đó.

## BWT: Cùng một câu hỏi, hai mốc so sánh

Nếu **F** hỏi “model đã quên bao nhiêu trên task cũ?”

<BlockMath formula="\text{F trên một task}=\text{điểm làm mốc}-\text{điểm hiện tại}" />

Thì **Backward Transfer (BWT)** hỏi theo chiều ngược lại: sau khi học task mới, model làm task cũ tốt hơn hay kém đi bao nhiêu so với cùng mốc đó?

<BlockMath formula="\text{BWT trên một task}=\text{điểm hiện tại}-\text{điểm làm mốc}" />

Nói cách khác, trong quy ước của survey <Cite paper="shi2024continualSurvey" evidence="core-cl-metrics-01-shi2024continualSurvey" />:

<BlockMath formula="\operatorname{BWT}_t^{\mathrm{survey}}=-F_t^{\mathrm{peak}}" />

**BWT dương** nghĩa là model làm task cũ tốt hơn; **BWT âm** nghĩa là model làm task cũ kém đi. Giá trị càng cao càng tốt.

### Quy tắc khác để tính BWT

Một số paper khác, chẳng hạn GEM, quy ước tính BWT bằng cách lấy **điểm ngay sau lần đầu model fine-tune trên task đó** làm mốc, tức phần tử đường chéo <InlineMath formula="P_{j,j}" /> của bảng kết quả phía trên (performance matrix) <Cite paper="lopez2017gradient" evidence="core-cl-metrics-03-lopez2017gradient" />.

Ví dụ ta tính lại BWT theo ví dụ ba task A, B, C ở trên:

<BlockMath formula="\operatorname{BWT}_3^{\mathrm{GEM}}=\frac{(60-80)+(75-85)}{2}=-15\text{ điểm}" />

Công thức tổng quát của quy ước GEM là:

<BlockMath formula="\operatorname{BWT}_t^{\mathrm{GEM}}=\frac{1}{t-1}\sum_{j=1}^{t-1}\left(P_{t,j}-P_{j,j}\right)" />

<LessonNote tone="warning">
  Trong ví dụ trên rất may mắn cả hai cho cùng dấu, tuy nhiên chúng có thể rơi vào trường hợp khác dấu nên khi đọc `BWT` trong một paper, hãy kiểm tra công thức dùng **mốc đỉnh** hay **mốc ngay sau lần đầu fine-tune**. Xem câu hỏi BWT trong node **Quiz** kế tiếp để thấy một ví dụ cụ thể khi hai quy ước cho kết quả khác dấu.
</LessonNote>

## FWT: Kiến thức cũ có giúp task tương lai?

**Forward Transfer (FWT)** trả lời cho câu hỏi liệu những task đã học có giúp model thực hiện một task tương lai tốt hơn, dù model chưa fine-tune trên task đó hay không?

Trên một task tương lai:

<BlockMath formula="\text{FWT}=\text{điểm trước khi fine-tune task}-\text{điểm baseline}" />

**Sau khi model học Task A nhưng chưa fine-tune Task B**

<MetricBars
  ariaLabel="Hiệu năng trên Task B trước và sau khi model học Task A"
  columns={2}
  max={100}
  items={[
    { label: 'Task B - Trước khi học A', value: 30, valueLabel: '30%', tone: 'neutral', dividerAfter: true },
    { label: 'Task C placeholder at checkpoint B', value: 0, valueLabel: '', placeholder: true, dividerAfter: true },
    { label: 'Task B - Sau khi fine-tune trên A', value: 40, baselineValue: 30, valueLabel: '40%' },
    { label: 'Task C placeholder after A', value: 0, valueLabel: '', placeholder: true },
  ]}
/>

<BlockMath formula="\operatorname{FWT}_2=\frac{40-30}{1}=10\text{ điểm}" />

<LessonNote tone="warning">
  **Hãy để ý:** tại checkpoint này, Task B chưa từng được dùng để fine-tune hay cập nhật trọng số của model; nó chỉ được dùng để đánh giá. Nhờ vậy, FWT đo công bằng khả năng model chuyển kiến thức sang một task chưa học, thay vì đo lợi ích từ việc đã huấn luyện trực tiếp trên chính task đó.
</LessonNote>

Giả sử chúng ta fine-tune tiếp **Task B**. Trước khi fine-tune Task C, model được đánh giá trên Task C để xem kiến thức từ A và B có tạo ra lợi thế hay không:

<MetricBars
  ariaLabel="Hiệu năng trên Task B và Task C trước khi model fine-tune trực tiếp từng task"
  columns={2}
  max={100}
  items={[
    { label: 'Task B - Trước khi học A', value: 30, valueLabel: '30%', tone: 'neutral', dividerAfter: true },
    { label: 'Task C - Trước khi học A', value: 35, valueLabel: '35%', tone: 'neutral', dividerAfter: true },
    { label: 'Task B - Sau khi fine-tune trên A', value: 40, baselineValue: 30, valueLabel: '40%' },
    { label: 'Task C - Sau khi fine-tune trên A và B', value: 50, baselineValue: 35, valueLabel: '50%' },
  ]}
/>

<BlockMath formula="\operatorname{FWT}_3=\frac{(40-30)+(50-35)}{2}=12.5\text{ điểm}" />

Với nhiều task tương lai, FWT lấy trung bình các mức chênh lệch này:

<BlockMath formula="\operatorname{FWT}_t=\frac{1}{t-1}\sum_{i=2}^{t}\left(P_{i-1,i}-b_i\right)" />

Trong đó, <InlineMath formula="P_{i-1,i}" /> là điểm trên Task <InlineMath formula="i" /> sau khi model học các task trước đó nhưng **chưa fine-tune trực tiếp Task** <InlineMath formula="i" />; <InlineMath formula="b_i" /> là điểm baseline của task đó.

- <InlineMath formula="\operatorname{FWT}>0" />: các task đã học giúp model làm task tương lai tốt hơn baseline.
- <InlineMath formula="\operatorname{FWT}=0" />: các task đã học chưa tạo ra khác biệt.
- <InlineMath formula="\operatorname{FWT}<0" />: các task đã học khiến model làm task tương lai kém hơn baseline.
