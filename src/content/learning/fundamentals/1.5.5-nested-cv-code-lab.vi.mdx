## Khóa protocol lựa chọn mô hình

Các lab trước đã cho thấy cách fit, so sánh và đọc metric. Lab cuối nối chúng thành quy trình end-to-end: chọn model bằng development, ước lượng toàn bộ thủ tục lựa chọn bằng outer CV, rồi mới đánh giá cuối trên holdout.

Ta giữ nguyên dataset, feature allowlist, ngưỡng nhãn 3.5 tỷ và ngưỡng quyết định 0.5. Metric tối ưu là AP. Grid gồm ba họ mô hình với hai cấu hình mỗi họ. Xác định grid trước khi đọc outer scores; nếu liên tục sửa grid vì outer score thấp, outer loop cũng trở thành dữ liệu tuning.

Tải [ml_labs.py](/learning/fundamentals/labs/ml_labs.py) và [requirements.txt](/learning/fundamentals/labs/requirements.txt) vào cùng một thư mục. Dùng Python 3.11–3.13 trong terminal; đây là Scikit-Learn thật, không chạy bằng nút Trực quan hóa của Workspace. Nếu đã cài môi trường ở lab trước thì dùng lại.


## Inner loop chọn, outer loop đánh giá

Trong mỗi outer fold, GridSearchCV chỉ nhìn outer-training. Ba inner fold chọn cả estimator và hyperparameter, đồng thời fit lại imputer/scaler/encoder trong từng inner-training. `refit=True` huấn luyện cấu hình thắng trên toàn outer-training, rồi mới dự đoán outer-validation.

Sau ba outer fold, ta có ba điểm đánh giá cùng **thủ tục search**, không nhất thiết cùng một cấu hình thắng. Độ lệch chuẩn của chúng mô tả biến động, không tự tạo thành confidence interval.

Cuối cùng chạy lại đúng search đó trên toàn bộ 480 dòng development. Cấu hình được chọn từ lần search này, không phải lấy outer fold có điểm đẹp nhất. Hàm dưới định nghĩa đầy đủ search được dùng ở cả hai giai đoạn.

```python
def make_search():
    grid = [
        {"model": [LogisticRegression(max_iter=1000)], "model__C": [0.1, 1.0]},
        {"model": [RandomForestClassifier(n_estimators=60, random_state=SEED)],
         "model__max_depth": [3, 6]},
        {"model": [GradientBoostingClassifier(n_estimators=60, max_depth=2, random_state=SEED)],
         "model__learning_rate": [0.05, 0.1]},
    ]
    return GridSearchCV(
        pipeline(LogisticRegression(max_iter=1000)), grid,
        scoring="average_precision",
        cv=StratifiedKFold(3, shuffle=True, random_state=11),
        refit=True, error_score="raise", n_jobs=1,
    )
```

## Chạy Nested CV trên development

Đoạn sau là hàm tương ứng trong file tải về, dùng các import và helper chung của module. Lệnh ở trang đầu gọi trực tiếp hàm này; không cần ghép code của lab khác.

```python
def nested_lab(evaluate_test=False, artifact=None):
    X, y = classification_data(development())
    outer = StratifiedKFold(3, shuffle=True, random_state=23)
    scores = []
    for train_ids, val_ids in outer.split(X, y):
        search = make_search()
        search.fit(X.iloc[train_ids], y.iloc[train_ids])
        probability = search.predict_proba(X.iloc[val_ids])[:, 1]
        scores.append(average_precision_score(y.iloc[val_ids], probability))
    print("Outer AP:", np.round(scores, 4))
    print("Outer mean/std (not a confidence interval):",
          np.mean(scores), np.std(scores, ddof=1))
    final = make_search().fit(X, y)
    print("Final development-selected parameters:", final.best_params_)
    if evaluate_test:
        if artifact is None:
            raise ValueError("Choose a NEW --artifact path for final evaluation.")
        path = Path(artifact)
        # Refuse overwrite before reading holdout: a reminder, not a security boundary.
        with path.open("xb") as output:
            joblib.dump({
                "pipeline": final.best_estimator_, "features": FEATURES,
                "price_threshold": PRICE_THRESHOLD, "decision_threshold": 0.5,
                "dataset": "synthetic-housing-v1", "seed": SEED,
            }, output)
        _, test_ids = partitions()
        X_test, y_test = classification_data(housing().loc[test_ids])
        probability = final.predict_proba(X_test)[:, 1]
        print("FINAL test AP:", average_precision_score(y_test, probability))
        print("FINAL test ROC-AUC:", roc_auc_score(y_test, probability))
        print("FINAL test F1 at 0.5:", f1_score(y_test, probability >= 0.5))
        restored = joblib.load(path)  # Only load your own trusted artifact.
        np.testing.assert_allclose(
            restored["pipeline"].predict_proba(X_test)[:, 1], probability,
        )
        print("Saved full pipeline:", path)
    else:
        print("Test remains unopened. Freeze protocol before --evaluate-test.")
    return scores
```

## Mở test một lần và lưu pipeline

Chạy mặc định chỉ in outer scores và cấu hình chọn từ development, chưa mở holdout. Khi đã khóa feature, grid, metric và threshold, chạy bước cuối với đường dẫn artifact mới:

```bash
python ml_labs.py nested --evaluate-test --artifact housing-final.joblib
```

Code từ chối ghi đè artifact đã tồn tại trước khi đọc test. Đây là lời nhắc quy trình, không phải cơ chế bảo mật: đổi tên file vẫn có thể chạy lại, nhưng sau khi dùng kết quả test để chỉnh model thì tập này không còn là đánh giá cuối độc lập. Nếu phải sửa lỗi hay đổi protocol, ghi rõ lý do và chuẩn bị đánh giá mới phù hợp.

AP, ROC-AUC và F1 được báo cáo trên cùng một lần dự đoán holdout. Lưu toàn bộ pipeline cùng tên feature, ngưỡng nhãn, ngưỡng quyết định và phiên bản dataset. Sau đó load lại **artifact do chính bạn tạo** và kiểm tra xác suất không đổi; không load file joblib không đáng tin vì có thể thực thi mã.

Outer CV vẫn chỉ đại diện dữ liệu mô phỏng i.i.d. này. Dữ liệu production bị shift, lặp người dùng hoặc có thứ tự thời gian cần thiết kế split phù hợp. Sáu lab tạo một quy trình có thể kiểm tra được, không biến một metric tốt thành bảo đảm triển khai.
