## Cùng dữ liệu, đổi câu hỏi dự đoán

Vẫn là những căn nhà trước đó, nhưng câu hỏi đổi thành: giá có đạt ít nhất 3.5 tỷ không? Đây là **quy tắc nhãn cố định** dùng cho ví dụ kinh doanh, không phải ngưỡng lấy từ phân vị của toàn bộ dataset.

Giá chỉ dùng để tạo y; X vẫn gồm năm feature trước bán. Đưa giá hoặc thuế sau giao dịch vào X sẽ làm bài phân loại mất ý nghĩa. Không tạo dataset mới hay chia lại holdout vì đổi từ hồi quy sang phân loại.

Tải [ml_labs.py](/learning/fundamentals/labs/ml_labs.py) và [requirements.txt](/learning/fundamentals/labs/requirements.txt) vào cùng một thư mục. Dùng Python 3.11–3.13 trong terminal; đây là Scikit-Learn thật, không chạy bằng nút Trực quan hóa của Workspace. Nếu đã cài môi trường ở lab trước thì dùng lại.

```bash
python -m venv .venv

.venv\Scripts\python -m pip install -r requirements.txt

```

Trên macOS/Linux, thay `.venv\Scripts\python` bằng `.venv/bin/python`. Các lệnh `python ml_labs.py ...` ở phần sau giả định bạn đã kích hoạt môi trường này. Chỉ bước cài thư viện cần mạng; dữ liệu được tạo tại chỗ. Không cần tải dataset ngoài.

## Xây preprocessing bên trong pipeline

Numeric và categorical cần hai nhánh xử lý khác nhau. ColumnTransformer ghép hai nhánh thành một ma trận rồi chuyển cho Logistic Regression. Dense output được dùng vì dataset nhỏ và để dùng cùng factory với Gradient Boosting ở lab sau.

`handle_unknown="ignore"` giúp category mới không làm chương trình lỗi: phần one-hot của feature đó sẽ toàn 0. Điều này không có nghĩa mô hình đã hiểu khu vực mới, nên vẫn cần theo dõi drift và tỷ lệ category chưa gặp khi triển khai.

Chia development bằng stratification để tỷ lệ hai lớp gần nhau giữa train và validation. Toàn bộ imputer, scaler, encoder và model chỉ fit trên training split. Phần code chung có thể xem trực tiếp trong file tải về ở các hàm `preprocessor` và `pipeline`.

```python
def preprocessor():
    numeric = Pipeline([
        ("impute", SimpleImputer(strategy="median")),
        ("scale", StandardScaler()),
    ])
    categorical = Pipeline([
        ("impute", SimpleImputer(strategy="most_frequent")),
        ("encode", OneHotEncoder(handle_unknown="ignore", sparse_output=False)),
    ])
    return ColumnTransformer([
        ("numeric", numeric, NUMERIC),
        ("categorical", categorical, CATEGORICAL),
    ], remainder="drop")


def pipeline(model):
    return Pipeline([("preprocess", preprocessor()), ("model", model)])
```

## Huấn luyện và xử lý category chưa gặp

Đoạn sau là hàm tương ứng trong file tải về, dùng các import và helper chung của module. Lệnh ở trang đầu gọi trực tiếp hàm này; không cần ghép code của lab khác.

```python
def classification_lab():
    X, y = classification_data(development())
    train_ids, val_ids = train_test_split(
        np.arange(len(X)), test_size=0.25, random_state=SEED, stratify=y,
    )
    model = pipeline(LogisticRegression(max_iter=1000))
    model.fit(X.iloc[train_ids], y.iloc[train_ids])
    probability = model.predict_proba(X.iloc[val_ids])[:, 1]
    print("Validation ROC-AUC:", roc_auc_score(y.iloc[val_ids], probability))
    print("Validation AP:", average_precision_score(y.iloc[val_ids], probability))
    print("Validation F1 at 0.5:", f1_score(y.iloc[val_ids], probability >= 0.5))
    new_home = X.iloc[[val_ids[0]]].copy()
    new_home["district"] = "new_district"
    assert np.isfinite(model.predict_proba(new_home)).all()
    print("Encoded columns:", model["preprocess"].get_feature_names_out())
    return model
```

## Đánh giá xác suất và quyết định

ROC-AUC và Average Precision (AP) dùng xác suất để đo chất lượng xếp hạng. AP không đồng nhất với diện tích PR tính bằng quy tắc hình thang. F1 dùng quyết định tại ngưỡng 0.5; nó có thể thay đổi khi đổi ngưỡng dù ROC-AUC không đổi.

Thử thay district của một dòng validation bằng `new_district` kiểm tra pipeline không crash. Đây là kiểm tra kỹ thuật, không phải bằng chứng chất lượng dự đoán ở khu vực mới. Kiểm tra tên cột sau encode giúp thấy rõ đầu vào của estimator.

Bạn có thể thử vài ngưỡng trên validation để hiểu Precision/Recall, nhưng khi đó ngưỡng cũng trở thành một phần của model-selection. Phải khóa nó trước test và đưa quá trình chọn ngưỡng vào inner loop nếu muốn đánh giá bằng Nested CV. Chuỗi lab này giữ ngưỡng 0.5 cố định để tập trung vào pipeline.
